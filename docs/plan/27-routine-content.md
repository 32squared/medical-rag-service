## 0. 카피 규칙 (작성·리뷰 공통 체크리스트)

### 0-1. 어휘 표준

| 개념 | 쓰는 말 | 절대 쓰지 않는 말 |
|---|---|---|
| 사용자 호명 | (2인칭 생략) · "생활" · "요즘" | 환자 · 대상자 · 회원님의 질환 |
| 종합 판정 | **밴드** = 안정 / 주의 / 경고 (+ 응급) | 정상인 / 고혈압 / 당뇨 / 전단계 |
| 항목별 구간 | **구간** = 정상 / 주의 / 경고 / **미측정** | 이상 / 비정상 / 위험 / 빈칸 |
| 추세 | **안정유지 / 지속상승 / 불안정반복** | 좋아졌어요 / 나빠졌어요 / 개선 / 악화 |
| 행동 결과 | "기록이 남았어요" · "이어졌어요" | 혈압이 내려가요 / 당수치가 좋아져요 |
| 미실천 | "쉬어간 날" · 회색 '–' | 결석 · 실패 · 미달 · 놓친 날 |
| 트랙 | 식이 기록 / 활동 기록 / 생활 리듬 | 식단 치료 / 운동 처방 / 습관 교정 |

### 0-2. 금칙 (하나라도 걸리면 그 카피는 폐기)

1. **의료법 27조** — 질환명으로 사람을 규정하지 않는다. "고혈압이에요"(❌) → "지금은 주의 구간으로 보여요"(⭕).
2. **WC-C1 효능표방** — 건강 결과를 약속하지 않는다. 카피는 **행동만** 말한다. "12주 뒤 수치가 좋아져요"(❌) → "12주 뒤 내 기록 84일치가 남아요"(⭕).
3. **WC-C2 처방성** — 용량·목표심박·치료식 표현 금지. "하루 나트륨 2,000mg 이하"(❌) → "국물은 절반만 남기기"(⭕).
4. **무비난** — 결석 일수·미실천 개수를 세어 보여주지 않는다. 붉은색·죄책감·카운트다운·"또 못 하셨네요" 전부 금지.
5. **인과 주장 금지** — "실천해서 좋아졌어요"(❌) → "같은 기간의 기록이에요"(⭕).
6. **안티골** — 랭킹·리더보드, 연속 끊김 카운트다운, 미완료 숫자 배지, 전면 축하 모달(D1 첫 성공 1회만 예외), 밴드 개선 연동 보상. 카피도 만들지 않는다.

### 0-3. 밴드별 카피 캡 (§B-4)

| 밴드 | 보조 행동 | 매 주차 배너 | 게임 요소 문구 | 확장기 진입 |
|---|---|---|---|---|
| 안정 | 1~2주 0 → 3~6주 1 → 7~12주 2 | 없음 | 전부 노출 | 3주차 |
| 주의 | 최대 1 | **"진료와 병행하세요" 상시** | 전부 노출 | 4주차(1주 지연) |
| 경고 | **0 (12주 내내 메인 1개)** | **진료 우선 배너 최상단 고정** | **스트릭·배지·레벨 문구 전부 숨김** | 없음 |

경고 밴드에서는 §2-5의 치환 셀을 쓴다. 행동 추가형 미션 문구를 **측정·기록형**으로 바꾼 판본이다.

#### 코드 동기화 (필수)

`coaching_engine._select_keys()`가 **문자열 리터럴로 매칭**하므로, 라벨을 바꾸려면 옵션에 `value`를 분리해 넣고 매칭은 `value`로 해야 한다.

| 트랙 | 문항 | 새 라벨 | 매칭 `value` (기존 리터럴 유지) |
|---|---|---|---|
| diet | 1 | 거의 매일 / 주 2~3회 / 주 1회 이하 | `거의 매일` / `주 2~3회` / `드뭄` |
| diet | 2 | 짜게 먹는 편 / 보통이에요 / 싱겁게 먹는 편 | `강함` / `보통` / `약함` |
| exercise | 1 | 거의 안 함 / 가끔 / 주 3회 이상 | `거의 안 함` / `가끔` / `주 3회+` |
| habit | 1 | 수면 / 스트레스 / 금연·절주 | `수면` / `스트레스` / `금연·절주` (KB `tag`와 동일 — **변경 금지**) |

**3번 문항 교체 건**: 기존 `period`("목표 기간은? 2주 / 1개월 / 3개월+")는 12주 프로그램과 정면으로 어긋난다(2주를 고른 사용자에게 12주를 배정하게 된다). 위 표대로 **앵커 시각 문항**으로 교체하고, `routine_engine.generate_program()`이 `intake['period'] = '12주'`를 내부에서 채워 `coaching_engine._header()`가 "12주 저염 실천 플랜"을 만들게 한다. 답변은 `routine_program.anchor`와 `routine_notify_pref.hhmm` 기본값으로 흐른다.

**exercise 3번 기존 옵션 삭제**: "목표는? 활동량 늘리기 / **체중** / 체력" 중 `체중`은 체중감량 결과를 암시해 WC-C1에 걸린다. 위 문항으로 대체한다.

|---|---|

| 밴드 주의·경고 | 진료를 언제 받아보면 좋을까요? |

**모든 상담 답변 말미 CTA (필수)**: `이걸 이번 주 행동으로 넣을까요?`
- 성공: `보조 행동에 넣었어요. 오늘 홈에서 바로 보여요.`
- 409 `activation_lock`: `3일 정착 후에 항목을 늘릴 수 있어요. 지금은 오늘 것 하나만.`
- 409 `cap_reached`: `이번 주는 항목이 다 찼어요. 다음 주에 넣어드릴까요?` · [다음 주에 넣기] [지금은 괜찮아요]
- 경고 밴드: CTA 버튼 자체를 렌더하지 않는다(보조 0).

**질문칩 금칙**: "효과", "낫나요", "좋아지나요" 같은 결과 단어를 칩 문구에 넣지 않는다. 사용자가 직접 물으면 답변 단계의 컴플라이언스 레이어가 처리한다.
