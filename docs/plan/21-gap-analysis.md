# 21. 종합 비평 · 갭 분석 · 추가 기획 백로그

> 작성: 2026-06-23 · 5역할(기획자·아키텍트·비평가·데이터 아키텍트·UX 디자이너)로 현재 결과 전반을 비평하고 **빠진(추가 기획할) 요소**를 레지스터화.
> 원칙: 안전·컴플라이언스(의료법·비식별 라벨) 유지. **설계·기획만.**

---

## 0. 한 줄 결론

계획·디자인은 두껍지만(기획 18 · UX 19 · 탐색 20 + 확정 디자인), **실행 가능한 핵심 몇 개가 비어 있다**: ① 선제(Anticipatory) **트리거 엔진** ② **비즈모델·GTM** ③ **코칭 KB·검증** ④ **파트너 통합** ⑤ **실시간 신호 파이프라인**. 컴플라이언스는 계획됐으나 **미검증(법률)**.

## 1. 현재 자산 (있는 것)

- **의료 RAG**: 빌드+배포(엔진·방향2 개인화·가드레일·멀티턴·어드민·뷰어), 테스트 ~600+

- **웰니스 코드: 0** (전부 설계)

## 2. 5역할 비평 — 각 역할이 보는 최대 갭

| 역할 | 가장 큰 갭 |
|---|---|
| **비평가** | 계획·디자인 과잉 ↔ 웰니스 **코드 0**. 가장 새로운 Anticipatory의 **심장(트리거 엔진)이 미정**. 컴플라 **미검증**(법률 의견 아님). |
| **기획자** | **비즈모델·GTM·가격·파일럿·경쟁분석**(국내 건강앱)·로드맵 타임라인 부재. *"누가 왜 돈을 내나"* 미답. |
| **아키텍트** | **파트너 통합**(B2B2C 임베드·SSO·화이트라벨)·멀티테넌시·**선제 트리거 엔진**·**실시간 신호 파이프라인**·국내 LLM 경로 미설계. |
| **데이터 아키텍트** | 선제 **신호→이벤트→우선순위 데이터모델**·웨어러블/PHR **실시간 인입**·코칭 **성과 측정**·동의 원장 확장·보존/삭제 정책 미완. |
| **UX 디자이너** | **모션·인터랙션 스펙**(정적뿐)·선제 모델 **온보딩**(기대 설정)·**first-run**(데이터 없으면 선제 불가)·음성/멀티모달·접근성 **검증** 미흡. |

## 4. 추가 기획 백로그 (우선순위)

1. **G1 선제 트리거 엔진** — 신호 카탈로그 → 규칙(무엇/언제/빈도캡) → 안전 캘리브레이션 → 데이터모델. *Anticipatory의 심장 — 미루면 컨셉이 공허해진다.*
2. **G2 비즈모델·GTM** — B2B2C 과금 구조·파일럿·경쟁 포지셔닝.
3. **G3 코칭 KB·골든셋** — 콘텐츠 출처·검수 + "거짓안심/효능 0" 회귀.
4. **G5 파트너 통합** — 임베드·SSO·멀티테넌시·화이트라벨.
5. **G6 실시간 신호 파이프라인** — 인입 → 밴드 → 트리거.
6. (G4·G7 컴플라/동의는 [LAUNCH-READINESS](../LAUNCH-READINESS.md)와 연계 — 법률·외부 의존.)
