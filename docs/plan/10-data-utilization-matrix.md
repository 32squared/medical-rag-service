## 0. 한 줄 결론 (4관점 수렴)

09의 *프레임*(경계선 설계·6.x 엔진·관련성 게이트)은 옳다. 그러나 ① **파이프라인이 파싱 직후 사망**(아키텍트: 수신·파싱까지만 살아 있고 정규화→해석→주입은 0%), ② **신호 절반이 고아**(데이터분석가: 11종 미활용 + `air_quality`는 코드가 파싱 중인데 기획에서 누락), ③ **"다 활용" 압력 자체가 위험원**(비평가: 워치 ECG 판독=의료기기법, 웰니스 교차신호=유사과학, 라벨 국외이전 미결이 안전 서사 전체를 떠받침), ④ **그래도 전부 사다리에 배치 가능**(기획자: Lv1~Lv3 + 의도적 천장 5건). → "전부 활용"의 정직한 정의 = **모든 신호를 사다리에 배치(Lv0 방치 0), 단 충실활용 천장은 그 신호의 신뢰·위험·동의·근거가 정한다.**

## 1. 가장 중요한 사실 — 신호 사망점 (단일 배선점)

아키텍트가 코드로 특정: **6개 소스 중 단 하나도 답변에 도달하지 못한다.**

| 위치 | 사실 |
|---|---|
| `service_routes.py:84` | `parse_agent_inputs()`로 Vital/Air/PHR 파싱 |
| `service_routes.py:85-88` | 결과가 `summarize_for_audit()` **로그 한 줄로 끝남** |
| `service_routes.py:144-150` | `generate_response(...)` 호출에 **personal 인자 없음** |
| `rag_engine.py:1126` | `generate_response` 시그니처에 개인화 파라미터 부재 |
| `vital_reference_ranges` | 테이블·시드 존재하나 **`FROM vital_reference_ranges` 읽는 코드 0건** (lookup 소비자 없음) |

검증된 부재(Grep 0건): `ingest_server`·`consent_ledger`·`vital_rules`·`personal_context`·`personal_measurement`·`personal_record` — 전부 계획문서에만 존재.

## 3. 고아 신호 박멸 — 3대 선결 액션

데이터분석가 O1~O11을 3개 선결과제로 수렴. 이 셋이 "고아 0"의 열쇠다.

1. **검진수치 밴드 시드 11종 확장** (`seed_reference_ranges.py`) — O8 해소. **숨은 선결조건**: 시드 없으면 PHR 검진 활용 자체가 불가(라벨링 불가 → 원시값 노출 또는 LLM 역치 환각, 둘 다 불변식 위반). + 아키텍트 M7: 기존 시드의 자연어 rule(`"수축기 130-139 또는…"`)을 **기계가독 min/max 구조**로 — vital_rules 결정성의 전제.
2. **웰니스 밴드 체계 신설** — HRV·수면·활동·stress는 공인 임상 참조범위 없음(`seed:252` 자인). **임상밴드와 물리 분리된 웰니스 라벨 체계**를 신설해 단독은 "참고 추세"로만, 교차는 §3 화이트리스트로만(O2·O3·O4·O6).
3. **파생지표 계층 명문화** (09 §6에 신설) — 맥압·MAP·BMI·체중변화율·수면효율·HRV회복지표(O7). 전부 결정적 계산·원시값 비노출.

추가: **`air_quality` 활용 결정**(O11) — 코드가 이미 파싱(`vital_input.py:101`)하고 환경 시드(PM/CO2) 보유. 09 6소스에서 누락됨 → 호흡기 질의 교차 축으로 편입하거나 명시적 비활용 선언(둘 중 택일, 침묵 금지).

## 4. 활용 사다리 + 의도적 천장 (Lv0 방치 0)

기획자 산출 — 모든 신호를 Lv1(존재 ack·며칠내)→Lv2(밴드·추세)→Lv3(교차·shaping)에 배치. **Lv1 공통**: "존재·신선도 acknowledge + 관련 KB 인용" = 경계선 ② 엔진 거의 안 거치고 원시값0·거짓안심0 자동 만족하는 최저위험 진입점.

**의도적 천장 5건 (정직한 약속 — "방치"가 아니라 "위험 비례 활용")**:
1. 체지방·근육·내장지방 → **Lv2 천장**(임피던스 오차) — 추세·교차의 *근거*로 단정 금지.
2. 워치 SpO2/ECG 임상경고 → **Lv2 천장 + 재측정 권유**(웰니스 등급, 의료기기 아님).
3. 약물명·현재복용 → **영구 천장**(계열·과거시제까지만).
4. 사용자 채팅 타이핑 수치 → **영구 Lv0**(I4 — 출처 무검증, 활용=위험. 방치 아닌 안전설계).
5. EMERGENCY 경로 개인화 → **영구 Lv0**(I7 — 매 턴 무상태 재평가, 응급을 개인화가 가리지 않음).

**모든 Lv2+의 존재증명 = 개인화 유용성 리프트(on/off 차)**. 못 재는 레벨은 활용으로 카운트 안 함(07 "측정 없는 개선 금지").

**L1/L2 응급 통합 (치명)**: 08 §P1-5의 EMERGENCY L1/L2를 09 §6.3에 **명시 통합**. 개인 데이터발 응급 상향(극단 혈압 등)은 **L2(명료화 1질문)까지만**, L1(HARD STOP) 단독 트리거 금지. 안 하면 커밋 `a4b686e`가 고친 **응급 고착 버그가 개인 데이터발로 재발**.

**거짓안심 비대칭 설계**: 밴드를 "안정" 대신 **"현재 측정 기준 특이소견 없음(다른 위험요인은 별개)"** — 경고는 민감, 안심은 보수. 각 거짓안심 벡터(백의/가면 고혈압, 약 복용 중 정상, 워치 SpO2 과대측정, 검진 stale)를 골든셋 회귀 케이스로 박제.

## 7. 디바이스 시퀀싱 수정 (기획자)

09 §10 `혈압기→체중계→Vital→워치→PHR→OCR`은 대체로 정합. 2건 수정:

- **수정 A**: Vital Lv1(파싱 표면화)을 **체중계와 병렬**로 당김 — `vital_input.py` 계약이 이미 존재(배선만 남음)해 저비용.
- **수정 B**: OCR을 독립 순위에서 빼고 **"PHR Lv2 합류 입력경로"로 재분류** — 1~3인 팀이 독립 워크스트림으로 오해 방지(과범위 방어).

## 8. 미결 → 보수 디폴트 잠금 (비평가 최우선)

**§13-4 "밴드 라벨도 국외이전인가"는 미결이 아니라 차단 사유.** 09 안전 서사 전체가 "라벨만 국외로"(§2 경계선)에 기대는데, 라벨이 개인정보로 판정되면("혈압 경고+우울 과거력+위치"=식별 가능) 무너진다. → **법무 회신 전 보수 디폴트로 잠금**: 모든 personal label = 국외이전 대상 간주, §9-2 폴백(로컬 해석 + 비개인화 LLM)을 **기본값**. (07 D4 "보수표현 선출시"와 동형.)

추가 잠금: 민감정보(정신·암·감염병)는 indirect 브리징으로 **절대 표면화 금지**(direct 언급+동의 시만) + 수신시점 분리암호화·국내저장 강제. 파트너 push는 **동의 증빙 토큰 동봉 의무**(없으면 수신 거부).
