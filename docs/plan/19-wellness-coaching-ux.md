## 1. 정보구조(IA) · 내비게이션

코칭은 **의료 대화에서 진입**(허브 아님) → 진입 후 **코칭 홈이 허브**.

```
파트너 앱
└─ 건강 코치 섹션
   ├─ (진입) 의료 대화 M1 ──핸드오프──┐
   ├─ 코칭 홈 C5  ◀── 허브(진입 후)   │
   │   ├─ 오늘의 체크인 카드           │
   │   ├─ 스트릭·진척 요약             │
   │   └─ 코치 대화 바로가기           │
   ├─ [탭] 홈 C5 · 코치 C7 · 진척/보상 C8·C9 · 설정 C13
   └─ (안전) 경고밴드 배너 C11 · 시설안내 C12  ← 전역, 어디서든
```

- **하단 탭(코칭 진입 후)**: 홈 · 코치 · 진척 · 설정. (의료 대화는 별도 진입, 탭 아님.)
- **전역 안전 레이어**: 경고/응급 밴드 배너·진료 에스컬레이션은 어느 화면에서든 최상위(§4-B.7).

## 2. 화면 맵 (screen inventory)

| ID | 화면 | 그룹 | 핵심 |
|---|---|---|---|
| **M1** | 의료 대화·답변 | 의료(기존) | 답변 + 핸드오프 버튼 + referral(§3-A) |
| **C1** | 트랙 선택 | 온보딩 | 식단/운동/습관 칩 |
| **C2** | 문진(순차) | 온보딩 | 한 번에 한 문항·버튼(§4-A) |
| **C3** | 동의 | 온보딩 | 코칭·개인신호·푸시 동의(§6-A·정보통신망법) |
| **C4** | 첫 플랜·챌린지 시작 | 온보딩 | 플랜 + "2주 챌린지" + Lv.1 |
| **C5** | 코칭 홈(대시보드) | 일일 | 오늘 체크인·스트릭·진척 |
| **C6** | 체크인 | 일일 | 1탭 + 코치 응답·보상 |
| **C7** | 코치 대화 | 일일 | 적응·문의(LLM, WC-C 통과) |
| **C8** | 진척·주간 요약 | 일일 | 실천율·스트릭·추세 |
| **C9** | 배지·레벨·랭킹 | 보상 | 수집·등급·익명 리더보드 |
| **C10** | 완주 축하·다음 목표 | 완결 | 완주 배지·리워드·재참여 |
| **C11** | 경고밴드 배너·진료 에스컬레이션 | 안전 | 모달/배너, 전역(§4-B.7) |
| **C12** | 시설 안내(병원·약국) | 안전 | E-Gen·심평원 공공출처(§5.8) |
| **C13** | 설정 | 시스템 | 동의·푸시 시간·휴면/졸업·철회 |
| **N1** | 저녁 체크인 푸시 | 알림 | 21시 전·무비난 |
| **N2** | 스트릭-세이버 푸시 | 알림 | 끊기 직전·무비난(§4-B.10) |

## 3. 핵심 사용자 플로우 (4)

**F1 진입(온보딩)**
```
M1 의료답변 → [실천 코칭 받기] → C1 트랙 → C2 문진(3) → C3 동의 → C4 첫 플랜·챌린지 시작 → C5 홈
                                   (응급/순수정보면 버튼 미노출 §3-A.2)
```

**F2 일일 리텐션 루프**
```
N1 저녁 푸시 → C6 체크인(1탭) → 즉시 보상(스트릭·포인트·배지) → 코치 응답·적응 → C5 홈 갱신
   (미응답 시 → N2 스트릭-세이버 → 그래도 미응답 N일 → 무비난 재참여 §4-B.5)
```

**F3 완결·재참여**
```
C8 진척(기간 종료) → C10 완주 판정(실천율 70%+) → 배지·레벨업·리워드 → "다음 목표?" → C4(새 챌린지)
   장기: 습관 정착 → 졸업/유지 모드(C13)
```

**F4 안전 에스컬레이션(전역, 최우선)**
```
코칭 중 새 측정 = 경고/응급 밴드 → C11 모달(코칭 일시중단 + 진료 우선) → C12 시설안내
   응급(intent=emergency) → 코칭 차단 → 119/응급실(I7·WC-C4)
```
