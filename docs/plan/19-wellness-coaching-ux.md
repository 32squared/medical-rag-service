## 1. 정보구조(IA) · 내비게이션

코칭은 **의료 대화에서 진입**(허브 아님) → 진입 후 **코칭 홈이 허브**.

```
파트너 앱
└─ 건강 코치 섹션
   ├─ (진입) 의료 대화 M1 ──핸드오프──┐
   ├─ 코칭 홈 C5  ◀── 허브(진입 후)   │
   │   ├─ 오늘의 체크인 카드           │
   │   ├─ 스트릭·진척 요약             │
   │   └─ 코치 대화 바로가기           │
   ├─ [탭] 홈 C5 · 코치 C7 · 진척/보상 C8·C9 · 설정 C13
   └─ (안전) 경고밴드 배너 C11 · 시설안내 C12  ← 전역, 어디서든
```

- **하단 탭(코칭 진입 후)**: 홈 · 코치 · 진척 · 설정. (의료 대화는 별도 진입, 탭 아님.)
- **전역 안전 레이어**: 경고/응급 밴드 배너·진료 에스컬레이션은 어느 화면에서든 최상위(§4-B.7).

## 3. 핵심 사용자 플로우 (4)

**F1 진입(온보딩)**
```
M1 의료답변 → [실천 코칭 받기] → C1 트랙 → C2 문진(3) → C3 동의 → C4 첫 플랜·챌린지 시작 → C5 홈
                                   (응급/순수정보면 버튼 미노출 §3-A.2)
```

**F2 일일 리텐션 루프**
```
N1 저녁 푸시 → C6 체크인(1탭) → 즉시 보상(스트릭·포인트·배지) → 코치 응답·적응 → C5 홈 갱신
   (미응답 시 → N2 스트릭-세이버 → 그래도 미응답 N일 → 무비난 재참여 §4-B.5)
```

**F3 완결·재참여**
```
C8 진척(기간 종료) → C10 완주 판정(실천율 70%+) → 배지·레벨업·리워드 → "다음 목표?" → C4(새 챌린지)
   장기: 습관 정착 → 졸업/유지 모드(C13)
```

**F4 안전 에스컬레이션(전역, 최우선)**
```
코칭 중 새 측정 = 경고/응급 밴드 → C11 모달(코칭 일시중단 + 진료 우선) → C12 시설안내
   응급(intent=emergency) → 코칭 차단 → 119/응급실(I7·WC-C4)
```

## 4. 화면별 스펙 (wireframe-level) — 핵심 화면

> 본 증분 = 제품 중심 화면(C1~C10). 안전·시스템·알림(C11~C13·N1~N2)·M1 핸드오프 상세는 다음 증분.

### 4.1 온보딩 (C1~C4)
- **C1 트랙 선택** — 목적: 코칭 방향 선택. 요소: 🥗식단·🏃운동·😴습관 칩 + 1줄 설명·뒤로. 상태: **MVP는 식단만 활성**, 운동·습관 "준비 중". CTA: 선택 → C2.
- **C2 문진(순차)** — 목적: 맞춤 입력. 요소: 진행 표시(1/3)·질문·버튼 선택지·뒤로(이전 답 수정). 상태: 한 번에 한 문항(§4-A). CTA: 3문항 완료 → C3.
- **C3 동의** — 목적: 동의 취득. 요소: 토글 3개(① 코칭 시작[필수] ② 개인신호(밴드·추세·웨어러블) 반영[선택] ③ 푸시 수신[선택]) + 각 1줄·더보기. 상태: ②③ 미동의도 진행(L0 비개인화·인앱만). CTA: 동의 → C4. (§6-A·정보통신망법)
- **C4 첫 플랜·챌린지 시작** — 목적: 플랜 제시 + 게임 진입. 요소: 플랜 헤더(신호 라벨+문진 요약)·실천항목 체크리스트·근거[n]·안전배너(밴드 조건부)·"2주 챌린지 시작"·Lv.1. 상태: **경고밴드 → soft 플랜 + 진료배너**(§5.4). CTA: 시작 → C5.

### 4.2 일일 루프 (C5~C8)
- **C5 코칭 홈(허브)** — 목적: 매일 돌아오는 대시보드.
```
┌──────────────────────────────┐
│ 마이헬스케어 코치       Lv.2 ⭐ │
│ 🔥 5일 연속 · 이번 주 4/7      │
├──────────────────────────────┤
│ 오늘의 체크인                  │
│ 국물 반 남기기                 │
│ [ 네 ] [ 아니오 ] [ 외식 안 함 ]│
├──────────────────────────────┤
│ 2주 식단 챌린지   ▓▓▓▓▓░░ 9일  │
│ 코치와 대화하기              → │
├──────────────────────────────┤
│  홈  │  코치  │  진척  │  설정  │
└──────────────────────────────┘
```
  요소: 상단 Lv·스트릭🔥·주간 n/7 · 오늘의 체크인 카드 · 챌린지 진행바 · 코치 바로가기 · 하단탭. 상태: 완료 시 카드→"오늘 완료 ✓", 미완료=강조. CTA: 체크인→C6 · 코치→C7 · 진척→C8.
- **C6 체크인** — 목적: 1탭 기록 + 즉시 보상.
```
┌──────────────────────────────┐
│ ←  오늘의 체크인               │
├──────────────────────────────┤
│ 국물 반 남기셨어요?            │
│ [ 네 ✓ ]  아니오   외식 안 함  │
├──────────────────────────────┤
│ 🔥 5일 연속!   +10P   🏅 배지   │
│ 코치: 좋아요! 이번 주 4번째     │
│       실천이에요.              │
│ [ 계속 ]   [ 코치와 더 얘기 ]   │
└──────────────────────────────┘
```
  요소: 질문·3버튼 · (응답 후) 보상 버스트(스트릭·포인트·배지) · 코치 1줄 반응 · 계속/더 얘기. 상태: 잘됨=축하 / 안됨=**무비난 격려 + 단순화 제안**(§4-B.3). CTA: 계속→C5 · 더 얘기→C7.
- **C7 코치 대화** — 목적: 적응·문의(LLM). 요소: 채팅 UI·빠른질문 칩("플랜 너무 어려워요"·"외식 잦아요")·플랜 조정 제안. 상태: **모든 메시지 WC-C 통과**·경고밴드 시 진료 우선(§4-B.7). CTA: 조정 수락 → C4(갱신).
- **C8 진척·주간 요약** — 목적: 동기 가시화. 요소: 주간 실천율·스트릭 추이·달성 배지·목표 대비(상대표현). 상태: 데이터 부족=격려. CTA: 보상 상세 → C9.

### 4.3 보상·완결 (C9~C10)
- **C9 배지·레벨·랭킹** — 목적: 수집·등급 동기. 요소: 배지 그리드(획득/미획득 흐림)·레벨 게이지·**주간 익명 랭킹(옵트인)**. 상태: 랭킹 미동의=숨김. 안전: 보상=행동연동·**경고밴드 톤완화**(§4-B.4).
- **C10 완주 축하·다음 목표** — 목적: 마일스톤 + 재참여. 요소: 완주 트로피·배지·레벨업·요약(실천율·최장 스트릭)·"다음 목표"(연장/새 트랙)·졸업 옵션. 상태: 실천율 기준 완주/미완주 분기(미완주=**무비난 재도전**). CTA: 다음 목표 → C4 · 졸업 → C13.

### 4.4 안전·시스템·알림 (C11~C13 · N1~N2 · M1)

- **M1 의료 대화(핸드오프 지점)** — 목적: 의료 답변 + 코칭 진입. 요소: 답변·인용[n]·개인맥락 배지·[실천 코칭] 버튼(§3-A 조건부)·시설 링크. 상태: **응급=버튼 차단 + referral**(I7). 일관성 §9.
- **C11 진료 에스컬레이션(모달)** — 목적: 코칭 중 경고/응급 밴드 → 진료 우선. 요소: 모달·중립 설명·[병원 찾기]·[나중에]. 상태: **응급=119·코칭 차단**(I7). 트리거: 밴드 동적 재평가(§4-B.7 WC-C3/C4).
- **C12 시설 안내** — 목적: 병원·약국 중립 안내. 요소: 응급배너·지역 **자가입력**·디렉터리 링크(E-Gen·심평원). 컴플라: 특정병원 추천·영리알선 금지(§5.8).
- **C13 설정** — 목적: 동의·푸시·졸업·삭제권. 요소: 푸시 시간(21시 전)·동의 관리·데이터 연결·졸업/유지·**동의 철회·데이터 삭제**. 데이터: 철회 → 즉시 L0 · `conversation_id` 캐스케이드 삭제.
- **N1 저녁 체크인 푸시** — "오늘 ○○ 하셨어요?" · 21시 전 · 무비난. 탭 → C6.
- **N2 스트릭-세이버 푸시** — "○일 연속이 곧 끊겨요, 1초면 이어져요" · 무비난 · 정보통신망법 동의 기반(§4-B.10).

## 5. 컴포넌트 인벤토리 · 디자인 시스템

> ⚠️ 초판 목업이 "비율·간격·위계 없이 대충"이었던 근본 원인 = **토큰·그리드 시스템 부재**. 본 절이 그 시스템을 못박는다. 이후 모든 목업은 여기에 종속.

### 5.1 레이아웃 · 그리드
- **기기 비율 19.5:9**(예 393×852 pt) — 목업도 이 비율 준수(뭉툭 금지).
- 화면 좌우 패딩 **22** · 섹션 간 **24** · 안전영역 상(상태바 42)·하(홈 인디케이터).
- **8pt 스페이싱 스케일**: 4 · 8 · 12 · 16 · 20 · 24.

### 5.2 타이포 스케일
| 역할 | 크기/굵기 | 용도 |
|---|---|---|
| Display | 40 / 600 | 스트릭·완주 수치 히어로 |
| Title | 20 / 600 | 화면·이름 |
| Headline | 16.5 / 600 | 카드 제목·질문 |
| Body | 14 / 400~500 | 본문·리스트 |
| Caption | 12.5 / 400 | 보조·메타 |
| Micro-label | 11.5 / 600 (대문자·자간) | 섹션 라벨 |

자간: Display/Title 음수(-0.2~-1px). 위계는 **크기+굵기+색**으로, 굵기 남발 금지.

## 8. 접근성

- **터치 타깃 ≥44×44** · 본문 대비 **≥4.5:1**(Warm Light 채택으로 유리) · **색만으로 상태 구분 금지**(아이콘·텍스트 병행).
- **폰트 스케일 대응**(고령 사용자 큰 글씨) · **음성 입력**(핸즈프리) · 스크린리더 라벨.
- 라이트 테마 = 고령·저시력 가독성 ↑ (§5.3 채택 근거).

## 9. 의료 RAG 화면 일관성

- **톤 분리, 시스템 공유**: 의료(M1)=중립·고지 / 코칭=동기부여. 단 디자인 시스템(Warm Light·Pretendard·§5)·안전 게이트·인용[n]·개인맥락 배지는 **공통**.
- **핸드오프 연속성**: M1 → C1 전환 시 같은 시각 언어로 끊김 없이(§3-A 버튼).
- 선제(Anticipatory)는 양쪽에서 동일 원칙(중립·결정적 트리거·진단 아님).
