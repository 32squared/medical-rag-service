# 웰니스 코칭 에이전트 — 라우터·핸드오프·코칭 트랙 (기획 v0.1)

> 사용자 결정: ① **별도 에이전트 + 라우터** ② **사용자 선택 버튼 핸드오프** ③ **코칭 트랙을 사용자가 선택**(고정 범위 ❌).

## 0. 한 줄 결론

의료정보 RAG는 **"이게 뭐고, 걱정해야 하나"** 에서 멈춘다(의료법 27조 — 진단·처방·치료 불가 → 답변은 늘 "정보 + 의료진 상담"). 그 위에 **"그래서 뭘 실천하지"** 를 책임지는 **별도 웰니스 코칭 에이전트**를 라우터로 연결한다. 핸드오프는 **사용자 버튼**, 코칭 방향(식단/운동/습관)은 **사용자가 메뉴에서 선택**. 단, 웰니스도 무규제가 아니므로 의료 **안전 불변식(응급·경고 밴드 → 진료 우선)을 상속**한다.

핵심 원칙 한 줄: **"안전 게이트는 공유, 톤·KB·실천성만 코칭화."**

---

## 1. 왜 — 전략 (천장 vs 기회)

의료정보 답변은 구조적으로 막다른 길이다. 사용자의 진짜 욕구("혈압 낮추려면 뭘 해야?", "당뇨 식단", "살 빼는 운동")는 **행동**인데, 의료법 천장 때문에 거기서 끊긴다. 웰니스 코칭은 그 욕구를 받아 ① **실천 가능**하고 ② **재방문·지속(engagement)** 을 만들고 ③ **개인화 데이터(밴드·추세·웨어러블)가 가장 자연스럽게 빛나는** 영역이다.

| 축 | 의료정보 RAG (현행) | 웰니스 코칭 에이전트 (신규) |
|---|---|---|
| 사용자 질문 | "이게 뭐고 걱정해야 하나" | "그래서 뭘 실천하지" |
| 출력 | 정보 + 의료진 상담 권유 | 목표 → 단계 → 추적(플랜) |
| 톤 | 중립·고지·신중 | 동기부여·코칭·구체적 |
| 법적 위험 | 의료법 27조(진단·처방) | **낮으나 0 아님**(효능표방·영양/운동처방 경계) |
| KB | 공신력 의학정보(질병청·식약처 등) | 식단·운동·행동변화 가이드라인(공신력 출처) |
| 개인화 | 방향2 = 밴드 라벨만(최소) | **적극**(밴드·추세·웨어러블로 맞춤 플랜) |
| 성공지표 | 정답성·안전·인용 | 핸드오프 수락률·트랙 완주·재방문 |
| 천장 | 의료법(고정) | 행동변화 지속(제품 해자) |

→ 의료정보는 **신뢰의 입구**, 웰니스 코칭은 **지속의 엔진**. 핸드오프가 제품의 가치 전환점이다.

## 2. 아키텍처 — 라우터 + 2 에이전트 (+ 공유 안전 게이트)

```
                         사용자 질의
                              │
                              ▼
                  ┌───────────────────────┐
                  │  라우터 / 오케스트레이터  │  intent·도메인·대화상태 판정
                  └───────────┬───────────┘
            의학적 질의 │                    │ 식단·운동·습관 질의 / 코칭모드
                        ▼                    ▼
            ┌────────────────────┐   ┌──────────────────────────┐
            │  의료정보 RAG (현행)   │   │  웰니스 코칭 에이전트 (신규)   │
            │  의료법 가드레일       │   │  - 자체 KB(식단·운동·행동)     │
            │                    │   │  - 코칭 프롬프트·상태머신       │
            │  답변 끝 '실천 여지'  │   │  - 트랙 선택형(사용자가 고름)   │
            │  감지 → 핸드오프 버튼 │──▶│  - 개인화 강함(밴드·추세·워치)  │
            └─────────┬──────────┘   └────────────┬─────────────┘
                      └──────────┬────────────────┘
                                 ▼
                  ┌───────────────────────────┐
                  │   공유 안전 게이트(상속)       │  응급·경고 밴드 → 진료 우선,
                  │   I7 / 17 게이트 / 12 deny   │  치료·완치 효능 주장 차단(C20류)
                  └───────────────────────────┘
```

**컴포넌트**
1. **라우터** — 질의를 medical / wellness로 분기. 신호: ① intent(분류기 재사용) ② 도메인 키워드(식단·운동·체중·수면·습관) ③ **대화 상태**(이미 코칭 모드면 후속도 코칭으로). 처음엔 룰 기반(키워드+intent), 후에 LLM 분류 검토(§10).
2. **의료정보 RAG** — 현행 무수정. 단 답변 말미에 **'실천 여지' 감지** 훅 추가(식단·운동·습관 토픽이면 핸드오프 버튼 노출).
3. **웰니스 코칭 에이전트** — 신규. 자체 system_prompt·KB·상태머신. 트랙 선택 → 코칭 문진 → 맞춤 플랜.
4. **공유 안전 게이트** — 두 에이전트가 **같은** 안전 불변식을 통과. 코칭이라고 우회 불가(§5).

**대화 상태(mode)**: `medical` ↔ `wellness`(track 선택 후 `wellness:diet` 등). 라우터가 mode를 보고 후속 질의를 같은 에이전트로 유지(06 멀티턴 컨텍스트 재사용).

## 2-A. 라우터 상세 설계 (증분 2)

라우터 = 질의를 medical / wellness로 분기하는 얇은 결정 레이어. **핸드오프가 명시 버튼**이라 라우터 오분류 비용이 낮다(사용자는 항상 의료 답변을 먼저 받고, 코칭은 옵트인) → P1은 **룰 기반**으로 충분.

### 2-A.1 라우팅 신호 (우선순위 순, 위가 이김)
1. **응급(intent=emergency)** — 어느 모드든 **즉시 medical + 응급 안내**(라우팅 우회, I7 상속). 최우선.
2. **대화 모드(state)** — 이미 `wellness:track` 모드면 후속 질의는 그 트랙 유지(사용자 명시 전환 전까지).
3. **명시 액션** — '실천 코칭 받기' 버튼 클릭 = 결정적 wellness 진입 → 트랙 선택.
4. **intent 분류**(medical_classifier 재사용) — 진단·약물·증상 질의는 medical.
5. **도메인 키워드** — 식단·영양·운동·체중·수면·습관·금연·절주 → wellness 후보(단, medical 답변 후 코칭 버튼으로 유도가 기본).
6. **기본값** — 위 신호 없으면 **medical**(보수적 fail-closed).

### 2-A.2 룰 기반 vs LLM 분류
| | 룰(P1 채택) | LLM 분류(승급 후보) |
|---|---|---|
| 지연 | ~0ms | +200~500ms |
| 비용 | 0 | LLM 호출 |
| 결정성·감사 | 높음(키워드·intent·모드) | 낮음(설명가능성↓) |
| 자연어 트랙 요청 | 약함("스트레스 줄이고파"류 놓침) | 강함 |
| 안전 | 기본값 medical → 놓쳐도 안전 | 오라우팅 시 검토 필요 |

→ **P1 = 룰**(키워드 사전 + intent + 모드). **승급 트리거**: 룰 오분류율이 임계 초과하거나, 버튼 없이 자연어로 트랙을 요청하는 비중이 커질 때 LLM 분류 도입(룰은 fast-path로 유지).

### 2-A.3 모드 상태머신
- 상태: `medical`(기본) · `wellness:diet` · `wellness:exercise` · `wellness:habit`
- 전이: `medical` ──('실천 코칭' 버튼)──▶ 트랙 선택 ──(트랙)──▶ `wellness:{track}` ──(코칭 문진→플랜)
- **모드 중 의학 질의**(예: wellness:diet 중 "이 약 부작용?") → **medical로 보수적 분기**(코칭 톤 유지하되 의학 답변은 의료정보 에이전트). 안전 우선.
- **응급**은 어느 모드든 즉시 medical+응급. 모드 저장은 [conversation_context](../../conversation_context.py) 재사용([06](06-multiturn-design.md)).

### 2-A.4 안전 기본값 (fail-closed 라우팅)
- 애매하면 **medical 유지**(코칭은 명시 옵트인이라 놓쳐도 손해 없음).
- 경고/응급 밴드 + wellness 요청 → 코칭 진입은 허용하되 **§5 안전 캡 적용**(강한 플랜 보류·진료 우선).
- 라우터는 **안전 게이트를 우회할 수 없다** — 두 에이전트 모두 공유 게이트 통과(§2 다이어그램).

### 2-A.5 라우팅 의사결정 표
| 입력 | 현재 모드 | 판정 → 라우팅 |
|---|---|---|
| "혈압이 높게 나왔어요" | medical | 증상 질의 → **medical** (+실천 여지 시 코칭 버튼) |
| (의료답변 후) '실천 코칭' 클릭 | medical | 명시 액션 → **트랙 선택 메뉴** |
| "저염 식단 알려줘" | medical | 키워드(식단) → **medical 답변 + 코칭 버튼**(직접 wellness 아님) |
| "숨을 못 쉬겠어요" | any | 응급 → **medical + 응급**(우회) |
| "외식 줄이는 법" | wellness:diet | 모드 유지 → **wellness:diet** |
| "이 약 같이 먹어도 돼요?" | wellness:diet | 약물 질의 → **medical 분기**(안전) |

## 3. 핸드오프 UX — 사용자 선택 버튼 (문진/배지 패턴 일관)

핵심: **의학적 궁금증에서 시작 → 사용자가 원할 때 실천 코칭으로 전환**. 강제 아님, 옵트인.

```
🙋 혈압이 높게 나왔어요
💬 [의료정보] 일시적으로 높을 수 있어 재측정… 두통·가슴통증 동반 시 즉시 진료… [1][2]
   🔐 개인맥락 반영됨 — 혈압=경고                          ← 방향2 배지
   ┌──────────────────────────────────────────┐
   │ 💪 실천 코칭 받기  ← (실천 여지 감지 시에만 노출)        │
   └──────────────────────────────────────────┘
🙋 (실천 코칭 받기 클릭)
🧭 어느 쪽으로 도와드릴까요?  ← 트랙을 사용자가 선택
   [🥗 식단]  [🏃 운동]  [😴 생활습관]
🙋 (🥗 식단)
🩺 (코칭 문진 — 한 번에 한 질문, Claude Code 인풋 방식)
   (1/3) 평소 외식 빈도는?      [거의 매일][주 2~3회][드뭄]
   (2/3) 짠 음식 선호도는?      [강함][보통][약함]
   (3/3) 목표 기간은?          [2주][1개월][3개월+]
💬 [웰니스 코칭] 당신의 혈압=경고 + 잦은 외식 기준, 2주 저염 실천 플랜:
   ① 국물 반 남기기 ② 라면→주1회 ③ … (구체적·추적가능)
   ⚠️ 단, 혈압이 경고 구간이라 약·식이 조절은 진료와 병행하세요.   ← 안전 상속
```

**규칙**
- 핸드오프 버튼은 **실천 여지가 있을 때만**(식단·운동·습관 토픽). 순수 정보질의("이 약 성분?")엔 노출 안 함.
- **경고/응급 밴드**면 버튼 문구를 완화하고("진료와 병행하는 가벼운 생활수칙") 강한 플랜은 보류(§5).
- 트랙 선택·코칭 문진은 **이미 만든 버튼/문진 컴포넌트 재사용**(06, persona_test_server의 순차 문진).

## 4. 코칭 트랙 — 사용자 선택형 메뉴 (고정 범위 아님)

사용자가 **원하는 방향을 고른다**. 시작 카탈로그(이후 증분에서 확장):

| 트랙 | 입력(개인 신호) | 산출(플랜 구조) | KB 출처(예시) | 안전 캡 |
|---|---|---|---|---|
| 🥗 식단 | 혈압/혈당/BMI 밴드, 식습관 문진 | 2~4주 실천 항목 + 체크리스트 | 식약처·보건소 영양, WHO/대한영양사협회 일반지침 | 진단질환 **치료식 처방 금지** → 일반 식생활수칙. 경고밴드=진료 병행 |
| 🏃 운동 | 활동량·걸음·안정시심박(12 신호), 운동 문진 | 주간 운동량(WHO 150분 대비) 단계 | WHO 신체활동, 국민체육진흥 일반지침, ACSM 스크리닝 | 심혈관 위험·경고밴드 → **운동 전 의학적 clearance 안내**, 고강도 처방 금지 |
| 😴 생활습관 | 수면·스트레스·금연·절주(12 신호) | 습관 형성 루틴(작은 행동→추적) | 질병청 건강생활, 보건소 금연·절주 | 효능 주장 금지, 임상 라벨 금지 |

**공통**: 모든 플랜은 ① **구체적·실천가능·추적가능**(체크인) ② **상대 표현**(본인 기저선/공인 권장 대비) ③ **질병 치료·완치 표방 금지** ④ 경고·응급 시 **진료 우선 배너**.

### 4-A. 트랙 스펙 — 문진 → 플랜 → 체크인 (증분 4)

모든 트랙은 **동일 골격**: `트랙 선택 → 문진(3문항·한 번에 한 질문·버튼) → 개인신호+문진 병합 → 플랜 생성(§5 캡 통과) → 체크인 등록`. 문진/버튼은 [06 멀티턴](06-multiturn-design.md)·persona_test_server 순차 문진 컴포넌트 재사용.

#### 4-A.1 🥗 식단 트랙

- **문진(3문항)**
  - (1/3) 평소 외식·배달 빈도? `[거의 매일] [주 2~3회] [드뭄]`
  - (2/3) 짠 음식·국물 선호? `[강함] [보통] [약함]`
  - (3/3) 목표 기간? `[2주] [1개월] [3개월+]`
- **개인신호 입력**: 혈압/혈당/BMI **밴드 + 추세**(악화/개선). 원시값·진단명 미투입(§6).
- **플랜 예시**
  ```
  외식(거의 매일) + 혈압=주의 기준, 2주 저염 실천 플랜:
   ☐ ① 국물 반 남기기      ☐ ② 라면 주 1회로
   ☐ ③ 간장·소스 따로 찍기  ☐ ④ 채소 한 접시 추가
   ⚠️ 혈압 주의 구간 — 식이 조절은 진료와 병행하세요. [1][2]
  ```
- **체크인**: 항목별 done(bool), 주 1회 진척 요약.
- **§5 캡**: 치료식·목표 영양소 처방 금지(WC-C2) · 효능표방 금지(WC-C1) · **경고밴드=치료식 보류**, 가벼운 일반수칙만(§5.4).

#### 4-A.2 🏃 운동 트랙

- **문진(3문항)**
  - (1/3) 지금 운동 습관? `[거의 안 함] [가끔] [주 3회+]`
  - (2/3) 주로 가능한 활동? `[걷기] [홈트] [헬스·유산소]`
  - (3/3) 목표? `[활동량 늘리기] [체중] [체력]`
- **개인신호 입력**: 활동량·걸음·안정시심박([12](12-wearable-wellness-spec.md) 신호) + 심혈관 위험 밴드.
- **플랜 예시**
  ```
  현재 주 ~60분 → 4주에 걸쳐 WHO 권장(150분)의 60%까지 단계적:
   1주: 걷기 20분 × 3   2주: 25분 × 3   3주: 30분 × 3 …
   ⚠️ 가슴통증·호흡곤란 시 즉시 중단. 위험요인 있으면 운동 전 의료진 상담. [1]
  ```
- **체크인**: 주간 누적 분/세션 수.
- **§5 캡**: 위험군·경고밴드 → **운동 전 clearance 안내 + 고강도 보류**(WC-C2/C3) · 목표심박 % 처방 금지.

#### 4-A.3 😴 생활습관 트랙

- **문진(3문항, 1번 답에 따라 분기)**
  - (1/3) 가장 개선하고 싶은 것? `[수면] [스트레스] [금연·절주]`
  - (2/3) (예: 수면) 취침 규칙성? `[불규칙] [보통] [규칙적]`
  - (3/3) 목표 기간? `[2주] [1개월]`
- **개인신호 입력**: 수면·스트레스 밴드([12](12-wearable-wellness-spec.md), **중립 라벨만**).
- **플랜 예시**
  ```
  수면이 평소보다 짧은 편 — 2주 수면위생 루틴:
   ☐ ① 취침·기상 시간 고정   ☐ ② 자기 1시간 전 화면 줄이기
   ☐ ③ 카페인 오후 제한
   (금연·절주 선택 시: 보건소 금연클리닉·절주 상담 연계 동선) [1]
  ```
- **체크인**: 습관 일별 done(bool).
- **§5 캡**: 임상 라벨 해석 금지(WC-C5) · 효능 주장 금지(WC-C1) · 금연·절주는 **보건소 전문 자원 연계**.

#### 4-A.4 플랜 산출 표준 포맷 (공통 스키마)

모든 트랙 플랜은 동일 구조 → 렌더·가드레일 일관:

| 슬롯 | 내용 | 규칙 |
|---|---|---|
| **헤더** | "[본인 신호 라벨] + [문진 요약] 기준, [기간] 플랜" | 상대표현(§5.2-C) |
| **실천항목** | 3~5개, 각 [동사+구체+추적가능] | 체크박스, 처방성 금지(WC-C2) |
| **근거** | KB 인용 [n] | 화이트리스트만(WC-C5) |
| **안전 배너** | 밴드 조건부 | §5.4 매트릭스대로 |
| **톤** | 동기부여 + 가능성·권장 | 단정 금지(§5.2-C) |

#### 4-A.5 체크인 데이터 (→ §7 연계)

- `coaching_checkin`: **item_key별 done(bool) + ts** — 밴드·원시값 아님, **실천 여부만**(최소수집).
- 주기: 식단=주1 · 운동=주1(누적) · 습관=일별.
- 재방문 트리거: 체크인 미입력 N일 → (P4) 알림/리마인드 검토(§8).

## 5. 컴플라이언스 — 웰니스의 경계 (정밀화 · 증분 3, ⚠️ 무규제 자유지대 아님)

웰니스 코칭은 의료법 위험은 낮지만 **0이 아니다.** 별도 에이전트로 분리하는 이유 자체가 **경계를 코드로 강제**하기 위함. 본 절은 그 경계를 ① 법령별 트리거 ② 표현 사전 ③ 트랙·밴드 캡 ④ 코드 백스톱 ⑤ 감사로 정밀화한다.

> ⚖️ **단정 금지.** 아래 법령 해석은 **개발·설계용 보수적 가설**이며 법적 결론이 아니다. 출시 전 변호사 검토([LAUNCH-READINESS](../LAUNCH-READINESS.md) A)에서 확정한다. 의심스러우면 **더 보수적으로**(fail-closed).

### 5.1 법령별 상세 매핑 (트리거 → 안전경계 → 예시)

| 법령 | 무엇을 건드리면 위험(트리거) | 안전 경계(코칭 허용선) | ❌ 넘는 예 / ✅ 안전한 예 | 주 영향 트랙 |
|---|---|---|---|---|
| **의료법 27조**(무면허 의료행위) | 진단·처방·치료 행위, 질환 단정 | 진단·치료 일절 안 함, "정보·일반수칙 + 진료" | ❌"고혈압이네요, 이렇게 치료하세요" / ✅"혈압 관리에 일반적으로 권장되는 생활수칙은…" | 전 트랙 |
| **식품표시·광고법 8조**(질병 효능 표방) | 식품·식이가 질병을 **예방·치료·완치**한다는 표현 | 일반 영양수칙·상대표현, 효능 단정 금지 | ❌"이 식단이 당뇨를 낫게 합니다" / ✅"저염 식사는 일반적으로 권장되는 건강수칙입니다" | 식단 |
| **국민영양관리법**(영양사 면허) | 진단질환 대상 **맞춤 임상영양·치료식 처방**(치료 목표 영양소 처방) | 공인 권장 기준 인용·일반 식생활 교육 | ❌"신장병이니 단백질 0.6g/kg로 제한" / ✅"WHO·식약처는 나트륨 줄이기를 권장합니다" | 식단 |
| **건강기능식품법**(기능성 표시) | 특정 보충제·기능성 식품 효능 권유 | 보충제 권유 자체를 회피(식품·생활습관 한정) | ❌"오메가3 드시면 혈압 떨어져요" / ✅(보충제 권유 안 함) | 식단·습관 |
| **운동 스크리닝**(ACSM류·국민체육진흥 일반지침) | 심혈관 위험군에 **고강도 운동 처방**(의학적 clearance 없이) | 공인 권장량(WHO 150분) 일반 안내, 위험군 진료 선행 | ❌"매일 고강도 인터벌 30분"(경고밴드) / ✅"걷기 등 가벼운 활동부터, 운동 전 의료진 상담" | 운동 |
| **의료기기·임상라벨**([12](12-wearable-wellness-spec.md) 상속) | 웨어러블 합성점수·임상 라벨 해석 | 중립 밴드 라벨만(안정/주의/경고), 원시값·진단 미투입 | ❌"수면점수 42는 수면장애" / ✅"최근 수면이 평소보다 짧은 편" | 전 트랙 |

### 5.2 표현 사전 (lexicon) — 백스톱 스캐너의 시드

코드(§5.5 WC-C1/C2)가 검출할 **금지 어휘·패턴 ↔ 안전 재서술**. KB 텍스트·LLM 출력 **둘 다** 스캔.

**A. 효능·치료 표방 (차단 → 재생성)**

| ❌ 금지 패턴 | 왜 | ✅ 안전 재서술 |
|---|---|---|
| "(질환)을 낫게/치료/완치/고친다" | 의료법·식광법 | "(질환) 관리에 일반적으로 권장되는 수칙" |
| "(질환)을 예방한다" | 식광법 효능표방 | "건강 유지에 도움이 될 수 있는 일반수칙" |
| "약 없이도/약을 끊을 수 있다" | 치료 대체 암시 | "처방약은 의료진과 상의, 생활수칙은 병행" |
| "○○에 직빵/특효" | 효능 단정 | "일부 지침에서 권장하는 방법" |

**B. 처방성 표현 (완화 → 일반화)**

| ❌ 처방성 | 왜 | ✅ 일반화 |
|---|---|---|
| 진단질환 대상 **치료 목표 용량**("나트륨 1500mg로 제한") | 영양사·의사 영역 | "나트륨을 줄이는 것이 권장(공인 기준 인용)" |
| "이 질환엔 이 음식을 드세요"(치료식) | 임상영양 | "일반적으로 권장되는 식품군 소개" |
| 위험군 고강도 운동 처방(목표심박 %) | 운동 스크리닝 | "가벼운 활동부터, 운동 전 의료진 상담" |

**C. 단정 톤 → 가능성·권장 톤(공통)**: "낫습니다/떨어집니다"(단정) → "도움이 될 수 있습니다 / 일반적으로 권장됩니다". 모든 코칭 문장은 **출처(공인 지침) 또는 본인 기저선 대비 상대표현**을 동반.

### 5.3 트랙별 컴플라이언스 캡

| 트랙 | 1순위 법령 리스크 | 하드 캡(절대 금지) | 소프트 가드(완화 처리) |
|---|---|---|---|
| 🥗 식단 | 식광법·국민영양관리법 | 질병 효능 표방, 치료식 처방, 보충제 효능 권유 | 용량·목표치 → 공인 권장 인용으로 일반화 |
| 🏃 운동 | 운동 스크리닝 | 위험군 고강도 처방, 목표심박 처방 | 위험군·경고밴드 → clearance 안내 후 가벼운 활동만 |
| 😴 습관 | 의료법 광고·임상라벨 | 임상 라벨 해석, 치료 효과 주장 | 수면·스트레스 점수 → 중립 밴드 표현 |

### 5.4 밴드 × 트랙 코칭 허용 매트릭스 (가장 중요 — 안전 불변식 상속)

행=개인 밴드(결정엔진 산출), 열=트랙. 셀=허용 수위. **응급은 전 트랙 차단(I7 상속)**.

| 밴드 | 🥗 식단 | 🏃 운동 | 😴 습관 |
|---|---|---|---|
| **안정** | 정상 코칭 | 정상 코칭(공인 권장량) | 정상 코칭 |
| **주의** | 일반수칙 + 진료병행 배너 | 중강도까지 + 배너 | 정상 + 배너 |
| **경고**(예: 혈압 152/96) | **치료식 보류** → 가벼운 일반수칙만 + 진료우선 배너 | **고강도 보류** → 운동 전 clearance 안내 | 정상이되 진료우선 배너 |

"경고밴드 가벼운 일반수칙"의 허용선(§10-6 열린질문)은 **차기 증분에서 트랙별 화이트리스트**로 확정(예: 식단=물·국물 줄이기 OK / 특정 영양소 목표치 NO).

### 5.5 백스톱 가드레일 명세 — 코칭 레이어 전용 (WC-C 시리즈)

| **WC-C1** 효능표방 스캔 | §5.2-A 패턴(KB+LLM 출력) | blocked → 재생성 | C20 확장 |
| **WC-C2** 처방성 탐지 | §5.2-B(용량·치료식·목표심박) | 일반화 재생성 | 신규 |
| **WC-C3** 밴드 캡 | §5.4 위반(경고밴드 강한 플랜) | 강플랜 보류 + 진료우선 배너 | I-밴드 상속 |
| **WC-C4** 응급 차단 | intent=emergency | 코칭 진입 거부 → 응급 안내 | I7 상속 |
| **WC-C5** 출처 화이트리스트 | KB 출처 = 공인목록 외 | 인용 거부 | 의료 KB 원칙 상속 |

## 6. 개인화 연결 — 방향2의 자연스러운 확장

방향2(밴드 라벨 LLM 주입)는 의료정보에선 "최소 안전(밴드만)"이지만, **코칭에선 본령**이다. 코칭은 본질적으로 맞춤("당신의 혈압=경고 + 잦은 외식 → 저염부터").

- **입력 확장**: 의료정보는 밴드 라벨만. 코칭은 밴드 + **추세**(악화/개선) + [12 웨어러블 신호](12-wearable-wellness-spec.md)(수면·활동·걸음·안정시심박) + 코칭 문진 응답.
- **단계적 개인화**: 밴드 → 추세 → 목표 추적(체크인 히스토리).
- **컴플라이언스**: 코칭에서도 원시값·진단명은 LLM 미투입 원칙 유지(밴드·상대표현). 다만 활용 폭이 넓으므로 17 게이트의 코칭용 프로파일 별도 정의(다음 증분).

## 8. 로드맵 (단계)

| 단계 | 산출물 | 검증 |
|---|---|---|
| **P0 기획(현재)** | 본 문서 + 결정 정합 | 사용자 합의 |
| **P1 라우터+핸드오프 버튼** | 룰 기반 라우터(키워드+intent), 의료답변에 '실천 코칭' 버튼(KB 없이) | 버튼 노출 조건 정확, 경고밴드 완화 |
| **P2 단일 트랙 MVP** | 식단 **또는** 운동 1트랙 풀 경로(트랙선택→문진→플랜) | 안전 캡 통과, 플랜 구체성 |
| **P3 멀티 트랙** | 식단·운동·습관 3트랙 + 트랙 선택 메뉴 | 트랙별 안전 캡, 라우팅 정확 |
| **P4 추적·코칭 루프** | 체크인·재방문·진척 | 완주율·재방문 지표 |

각 단계는 의료정보 시스템 **무회귀**(별도 에이전트라 격리)를 전제.

## 9. 성공지표 / 리스크

**지표**
- engagement: 핸드오프 **수락률**, 트랙 **완주율**, **재방문**, 체크인 지속
- 안전: **경고/응급 밴드에서 강한 코칭 발생 0건**(차단율 100%), 효능표방 0건

**리스크**
- 경계 침범(코칭→치료 표방) → 별도 에이전트 + 코칭용 C20류 백스톱(효능표방 스캔)
- KB 품질·공신력 → 출처 화이트리스트(의료정보와 동일 원칙)
- 영양/운동 처방 경계 → 일반수칙 한정 + 진료/전문가 연계 동선
- 라우터 오분류 → 보수적 기본값(애매하면 의료정보 유지, 코칭은 명시 옵트인이라 안전)

## 10. 열린 질문 (다음 증분에서 고도화)

1. **라우터**: 룰(키워드+intent) vs LLM 분류 — 정확도/지연/비용 트레이드오프
2. **코칭 KB**: 출처 후보·수집 범위(식약처·보건소·WHO·전문학회 일반지침), 라이선스
3. **코칭 프롬프트/페르소나**: 톤(동기부여 강도), 분량, 플랜 포맷 표준
4. **추적(체크인)**: 범위(앱 내 체크 vs 알림), 이벤트 설계
5. **17 게이트 코칭 프로파일**: 코칭에서 개인 신호 활용 폭 확대 시 게이트 재정의
6. **경고밴드 코칭 정책**: "가벼운 일반수칙"의 구체 허용선(어디까지가 일반수칙인가)
7. **MVP 트랙 선정**: P2를 식단 vs 운동 중 무엇으로(개인화 데이터 적합도 기준)
