## KB 메타데이터 개선 (콘텐츠 추가만큼 중요)

1. **발행일·개정일 색인** — `_weighted_rerank`의 freshness 점수가 현재 "revised_at 미색인 → 0.5 중립 고정"(rag_engine.py). 모든 신규 수집에 `published_at`/`revised_at`을 의무화하면 **잠자고 있는 랭킹 인자 10%가 활성화**된다. 의학 정보는 최신성이 곧 정확성.
2. **evidence_level 실값 부여** — 현재 기본값 'B' 일괄. 출처 티어 기준으로 A(공식 지침)/B(공공 정보)/C(일반) 재라벨 → 가중 리랭크의 evidence_level 인자(5%)도 활성화.
3. **license·source_version·retrieved_at 의무화** — 감사 요건이자 갱신 파이프라인의 전제.
4. **evidence_topic 라벨 커버리지 확대** — 신규 적재분은 기존 GPT-5-mini 자동 라벨링 경로 재사용.

## 실행 원칙

- **gap 루프가 순서를 정한다**: 위 목록은 후보 풀이고, 실제 수집 순서는 `rag_gap_analysis.py`의 근거부족 주제 우선순위 큐를 따른다(수요 주도).
- **신규 출처 1개당**: `kb_sources` 등록(jurisdiction·priority_rank·license) → 수집기(기존 `collect_public_kb.py` 패턴) → 위반패턴 사전검사 → evidence_topic 라벨링 → 골든셋에 해당 출처 검증 문항 추가.
- **T2 학회 자료**: 제휴 협상과 병행해 "기준 수치의 사실 인용 + 출처 표기"의 저작권 검토를 먼저 받아 플랜 B 확보(레드팀 Should-fix #6).
