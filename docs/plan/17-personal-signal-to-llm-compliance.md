# 17. 비식별 개인 신호의 LLM 주입 — 의료법·개인정보 관리 방안

## 0. 배경 — 무엇이 바뀌나

- **현행(경계선 설계)**: 개인 측정값은 물론 **밴드 라벨조차 LLM에 미투입**. 결정적 엔진이 로컬에서
  해석해 답변 생성 *후* 별도 블록으로 붙인다. → 답변 본문은 사용자를 모름(개인화 약함).
- **방향 2(본 문서)**: **비식별 밴드 라벨**(안정/주의/경고)만 LLM 프롬프트에 넣어 답변 본문을
  사용자 상황에 맞춘다. **원시값·진단명·PII는 여전히 미투입.**

쟁점은 두 법:
1. **의료법 27조(무면허 의료행위)** — 서비스가 진단·처방을 하는가?
2. **개인정보보호법(민감정보·국외이전)** — 건강 신호를 (국외) LLM에 보내는가?

## 1. 의료법 27조 — 관리

| 위험 | 통제 |
|---|---|
| 밴드 라벨이 '진단'으로 읽힘 | 라벨은 **중립 3단(안정/주의/경고)** — 질환명/병기(고혈압 1기) 미투입. 프롬프트 지침에 "특정 질환 단정·진단·처방 금지, 의료진 상담 안내 포함" 명시 |
| LLM이 단정적 답변 생성 | 기존 **가드레일(ComplianceAnalyzer)**·인용검증·면책/상단고지 그대로 적용(생성 후) |
| 응급 상황 개인화 오용 | **G3**: 응급 질의는 개인 맥락 미주입(I7) |

→ 밴드 라벨은 비진단적 분류이고, 출력은 기존 안전 계층을 통과한다. **진단·처방 0 유지.**

## 2. 개인정보(민감정보·국외이전) — 관리

핵심: **데이터 최소화 + 동의 + 국외이전 통제 + 감사**.

| 원칙 | 적용 |
|---|---|
| 최소수집/최소전송 | 신호별 **밴드 라벨만**. 원시값·clinical_label·시점·PII·추세수치 미투입. 관련성 게이트로 질의 관련 신호만 |
| 비식별 | 프롬프트에 개인 식별자 없음. LLM 호출은 무상태(링크 미보존) |
| 동의 | **G2**: 민감정보 처리 동의 없으면 미주입 |
| 국외이전 동의 | **G4**: 국외(해외) LLM이면 별도 ack 없이는 미주입(fail-closed) |
| 국내 우선 | 국내(self-hosted 등) provider면 국외이전 자체가 없음 → 우선 경로 |
| 감사 | 주입 시 '밴드 라벨 주입' 사실을 로깅(라벨만, 원시값 0) |

## 3. 코드로 강제하는 게이트 (fail-closed)

`personal_llm_context.build_llm_context()` — 하나라도 실패하면 미주입(""):

| 게이트 | 환경변수 / 조건 | 기본값 |
|---|---|---|
| G1 기능 플래그 | `PERSONAL_SIGNAL_TO_LLM` | **off**(미설정 시 현행과 동일) |
| G2 동의 | 요청 `personal_consent=true` | off |
| G3 응급 | intent=='emergency'면 미주입 | — |
| G4 국외이전 | 국내 provider OK / 국외면 `ALLOW_CROSS_BORDER_PERSONAL` ack 필요 | off |
| G5 관련성 | 질의 관련 밴드만(과노출 차단) | — |
| G6 라벨-온리 백스톱 | `scan_personal_block`(원시값/진단명 0) | — |

`DOMESTIC_LLM_PROVIDERS`(기본 `self_hosted`)로 국내 provider type을 지정.

## 4. 주입되는 내용(예시)

```
[비식별 개인 맥락 — 참고용]
- 사용자의 최근 측정 구간(밴드): 혈압=주의, 산소포화도=안정
지침: 위는 비식별 밴드 라벨이며 원시 수치·진단명이 아니다. 이를 반영해 일반 의학정보를
사용자 상황에 맞게 강조하되, 특정 질환으로 단정하거나 진단·처방하지 말 것. 수치를
추측·생성하지 말고, 항상 의료진 상담 안내를 포함할 것.
```

원시값(152/96)·질환명(고혈압)·시점·PII는 **포함되지 않는다**(G6가 이중 검증).

## 5. 운영 권고 (production)

1. **국내 LLM 경로 우선** — 개인 신호 주입이 필요한 트래픽은 self-hosted/국내 모델로 라우팅
   → 국외이전 자체를 제거(G4 자동 통과). 국외 모델 사용 시에만 별도 국외이전 동의·ack.
2. 동의 원장(consent_ledger)에 '민감정보 LLM 활용' + '국외이전' 항목 분리 기록(향후 마이그 017+).
3. 골든셋에 "개인 맥락 주입 시 진단단정 0·거짓안심 0" 회귀 케이스 추가(E3 게이트).
4. 기본은 off로 배포 → 동의·국내경로·골든셋 통과 확인 후 단계적 활성화.
