# 20. 혁신적 UX 탐색 — "새로운 형태의 인터페이스"

> 작성: 2026-06-23 · 5역할(기획자·아키텍트·비평가·데이터 아키텍트·UX 디자이너)로 현재 결과를 비평하고 패러다임을 진화시킨다.
> 목표: 미감(Calm Intelligence)을 **넘어** 인터랙션 패러다임 자체를 새롭게 — "혁신적"이라 느껴질 때까지.
> 제약(불변): 의료법 27조·컴플라이언스·**비식별 밴드 라벨**·원시값 0(I1/I12)·응급 I7·코칭 WC-C. 혁신은 표현·상호작용에서, 안전선은 그대로.

## 1. 현재(Calm Intelligence) — 5역할 비평

| 역할 | 비평 |
|---|---|
| **비평가** | 예쁘지만 **구조는 관습적**(홈·대화·탭·카드). Oura·Whoop가 점유한 다크+글로우 미감 — "새 형태"가 아니라 "잘 만든 기존 형태". 차별이 미감에만 머묾. |
| **UX 디자이너** | 사용자는 여전히 **화면을 탐색**(탭 전환·스크롤). AI 제품인데 AI가 보조(인사이트 카드 1개)일 뿐 주체가 아님. AI-native라면 **UI가 맥락에서 생성**되고 네비게이션이 소멸해야. |
| **기획자** | 제품 본질 = "내 몸을 이해 → 행동으로 잇기". 그걸 여러 화면에 분산. 본질은 **하나의 살아있는 표상 + 그것과의 대화**로 압축 가능. |
| **아키텍트** | 화면 기반 = 라우팅·상태가 화면에 결합. 생성형은 "의도 → 컴포넌트 명세" **생성 계층**이 필요. RAG·방향2(비식별 밴드)가 그 입력. 컴플라이언스 게이트는 생성 컴포넌트에도 동일 적용. |
| **데이터 아키텍트** | 밴드·추세·웨어러블을 **정적 카드로 소비** 중. 같은 데이터를 **연속 상태(색·움직임·형태)**로 매핑 가능 — 단 원시값 노출 0·중립 라벨 유지, 생성 UI도 [015](../../migrations/015_analytics_events.sql) 비식별 기록. |

→ **결론**: 지금은 "아름다운 관습". 혁신은 **인터랙션 패러다임 전환**에서 온다.

## 2. 진화 컨셉 ② — **Living Canvas** (건강 유기체 + 생성형 대화)

**한 줄**: 화면·탭·대시보드를 없애고, **중앙의 살아있는 건강 표상**과 **자연어 대화**만 남긴다. UI는 맥락에 따라 **AI가 생성**한다.

- **리빙 표상(유기체)**: 중앙에 호흡하는 오로라 유기체. **밴드 → 시각 상태** 매핑 — 안정=잔잔한 호흡 / 주의=느린 파동 / 경고=가라앉은 톤 + 진료 신호. (원시값 0, 중립)
- **단일 입력이 유일한 상시 컨트롤**: 하단 자연어·음성. 묻는 순간 **AI가 필요한 컴포넌트를 생성**해 캔버스에 띄움(혈압→미니 추세, 식단→코칭 카드, 약→시설 안내).
- **네비게이션 없음** — 맥락이 화면을 만든다. "오늘"은 AI가 정한 **단 하나의 행동**.
- **안전 최우선 생성**: 경고/응급이면 유기체가 그 상태를 표현하고 **진료 카드가 최우선 생성**(I7·WC-C3/C4). 거짓안심·과불안 금지(중립 표현).

## 3. 아키텍처 함의 (생성형 UI)

- **생성 계층**: `intent → component spec(JSON) → 렌더`. 컴포넌트는 **화이트리스트**(추세·코칭·진료·시설·인사이트)만 — 임의 생성 아님(안전·예측가능).
- **상태 매핑**: 밴드·추세·웨어러블 → 유기체 파라미터(색상·진폭·속도). 결정적 매핑(LLM 아님), 비식별.
- **컴플라이언스**: 생성 컴포넌트도 가드레일·WC-C 통과. 유기체 상태 표현이 진단·효능으로 읽히지 않게(중립 라벨 원칙 상속).
- **데이터**: 생성·노출 이벤트는 015에 비식별(component_shown{type}, organism_state{band}).
