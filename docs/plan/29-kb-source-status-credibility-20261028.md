## 2. 공신력 기준으로 본 강점과 약점

**강점**
- 출처가 전부 국내 공적 기관·정부 고시·법령 아니면 의사 자문 자체 작성이라 정의 ① 에 가깝다. 출처 id·URL·라이선스가 문서 단위로 남아 있어 답변에 기관명을 표기할 수 있는 구조다.
- 한국 제도와 충돌하는 영역(예방접종·법정감염병)은 한국 출처만 쓰는 원칙과 도구(URL 정규화·언어/저밀도 필터·상세 URL 전개기·숏리스트 K1~K5)가 코드에 있다.

**약점**
1. **최대 출처(health_kdca, 문서의 37%·청크의 63%)가 공공누리 제4유형**이다. 상업 서비스에서 본문을 적재해 변형(청킹·요약)해 쓰는 것이 허용 범위 밖일 수 있다. 이 출처를 빼면 질환 일반 정보 커버리지가 거의 사라진다.
2. 자체 작성 문서(문진 99건·큐레이션 40건)는 "의사 자문 반영"이라고만 적혀 있고 **감수자·감수일이 데이터에 없다**. 3차 가이드라인 안의 "출처·근거·감수기관 명시" 요건을 못 채운다.
3. 라이선스 값이 출처 단위·insert-only 라 코드 값을 고쳐도 DB 행이 안 바뀐다. 제0유형·AI유형은 `ALLOWED_INGEST_LICENSES` 에 없다.
4. 답변 본문의 출처 표기 형식(기관명·연도·"참고용"·의료기관 상담 안내)은 아직 정해지지 않았다. API 에는 citations 와 source_name 이 있으나 본문에 어떻게 쓰는지는 프롬프트·후처리 설계가 필요하다.
5. 시의성: 수집 잡(collect-public-kb)이 6월 이후 돌지 않았고 갱신 주기 실행 체계가 없다. kb-stats·kb-rag-audit 잡은 5월 이미지라 지금 스크립트가 없어 실패한다.

## 3. 남은 과제 (우선순위)

**A. 라이선스·출처 정리 (사람·법무 결정 필요, 1~2주)**
- health_kdca 제4유형 처리: (가) 본문 제거하고 메타+딥링크만 (나) 질병관리청과 이용 협의 (다) 대체 출처로 교체. 결정 전까지 운영 적재 금지.
- nemc 영리 이용 협의 여부, 검진 고시 `public_domain` 해석, nip·lifecycle_kr 의 "자체 요약" 라벨 정정.
- kb_sources 라이선스 갱신 마이그레이션(update 가능하게) + 제0유형·AI유형 허용.
- 출처 티어 A/B/C·제외 목록·표기 형식 표를 medical-eval 에 전달(DOC-X4HAD §5 가 RAG 팀 REQ 로 예고, 아직 미접수).

**B. 운영 KB 를 dev 수준으로 (1주)**
- 운영 적재: 확장 시드 6종 + 검진 고시(라이선스 결정 뒤) + 덮어쓰기 감사 + evidence_topic 한국어 백필.
- kb-stats·kb-rag-audit·collect-public-kb 잡 이미지를 현재 main 으로 갱신.

**C. 커버리지 대체·보강 (2~4주)**
- 제4유형 대체: 질병관리청 보도자료(제0유형), KDCA OpenAPI(키 필요, `kdca_api` 비어 있음), e약은요(data.go.kr 키 필요), 학회 진료지침(메타+딥링크), MedlinePlus(퍼블릭 도메인, 보조, 수치는 한국 기준).
- 숏리스트 K1 PHWR(CC BY-NC → 논문별 CC BY 만)·K4 정신건강포털(제4유형) 보류 유지, K3/K5 는 health_kdca 결정에 따름.

**D. 감수 체계 (1~2개월, DOC-X4HAD 2단과 동일)**
- 자체 작성 문서에 reviewed_by·reviewed_at·reviewer_affiliation 메타 추가, 전문의 자문단 감수 확인서 수집, 답변에 「감수: 전문의 자문단(’26. 10)」 표기.

**E. 답변 출처 표기 (프롬프트·후처리, 1~2주)**
- 문장 끝 「기관명, 연도」, 집단 통계·연구 문장에 「참고용」+「정확한 확인은 의료기관 상담」, 수치 기준에 「국가건강검진 판정 기준」「대한당뇨병학회 진료지침(2023)」 노출. legal-v13 LG-20 출처 조건과 맞춘다.

**F. 전환 검증 (운영 RAG 대체 판단용)**
- medical-eval 배치(PHR 350·일반 650)를 자체 RAG dev 로 돌려 법률 위반·INSUFFICIENT·답변 품질을 운영 RAG 와 비교. 검진 질문 게이트는 9/29 기준 PASS/WEAK_PASS 가 대부분이고 콜레스테롤·크레아티닌 PHR·'전반' 질문은 INSUFFICIENT.
- 결정 대기 항목: 게이트 문턱 0.35(PR #18 미병합), 가드레일 fail-closed, 메인 모델 gpt-5 유지 여부.
