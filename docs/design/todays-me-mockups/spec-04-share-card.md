## 1. 화면 목적과 진입·이탈 경로

### 1-1. 목적

하루의 결과를 **한 장의 이미지**로 압축해 "자랑할 거리"를 손에 쥐어 준다. 이 화면의 성공은 공유 전송 수가 아니라 **사용자가 자기 카드를 마음에 들어 해서 저장까지 간 비율**로 본다. 친구 초대·랭킹·상호 비교 요소는 이 화면에 존재하지 않는다(브리프 §2 안티골, 정본 §0-2.6).

### 1-2. 진입

| 경로 | 조건 | 진입 방식 |
|---|---|---|
| 화면 3 리빌 → CTA "카드 만들기" | 완료 트랙 1개 이상 | 정규 경로. push 전환 |
| 캐릭터 도감 → 과거 카드 탭 | 해당 날짜 카드 존재 | 읽기 전용 + 재편집 진입. **재편집 허용 창 = 당일 00:10까지**(정본 25 E01 자정 유예 반영, 01-cross-review C5 확정). 이후 잠금. **카드 재생성은 불허** |
| 홈 상단 "오늘의 카드" 배너 | 오늘 카드가 이미 생성됨 | 재진입. 마지막 편집 상태 복원 |

**진입 불가 조건 (화면 자체가 없다)**

| 조건 | 처리 |
|---|---|
| 완료 트랙 0개 | 화면 3(리빌)이 생성되지 않으므로 이 화면도 도달 불가. 브리프 §4 "리빌 없음" |
| 밴드 = 경고 | **카드 기능 전체 숨김.** CTA·배너·도감 진입점을 렌더하지 않는다. 정본 §0-3 "경고 밴드는 게임 요소 문구 전부 숨김" |
| 밴드 = 응급 | 상동. 응급 모달 우선(정본 §3-6) |

### 1-3. 이탈

| 요소 | 목적지 |
|---|---|
| T4-01 뒤로 | 화면 3 리빌 (편집 내용은 도감에 자동 저장된 상태로 유지) |
| T4-40/41/42 공유·저장 | 외부 앱 or 사진 앱. 완료 후 이 화면으로 복귀 |
| 시스템 백/스와이프 | 화면 3 |

카드는 **화면 진입 즉시 도감에 자동 저장**된다(§8-3). 따라서 "저장 안 하고 나가면 사라지나요" 류의 확인 다이얼로그를 띄우지 않는다.

## 3. 카드 렌더 스펙 — 픽셀 단위

### 3-1. 미리보기 ↔ 실제 렌더 스케일

| 항목 | 값 |
|---|---|
| 목업 미리보기 실측 | **254 × 452 px** (`Card.dc.html` L51) |
| 지시서에 적힌 262×452 | 회전(−2°) 후 외곽 바운딩박스 추정치로 보인다. **스펙의 기준은 회전 전 실측 254×452.** |
| 미리보기 종횡비 | 254 / 452 = 0.5619 (9:16 = 0.5625, 오차 0.1%) |
| 9:16 렌더 해상도 | **1080 × 1920** |
| **스케일 계수 S** | **1080 / 254 = 4.2520**, 1920 / 452 = 4.2478 → **S = 4.25 로 고정**하고 잔여 0.05% 오차는 좌우 여백에 흡수 |
| 1:1 렌더 해상도 | **1080 × 1080** (미리보기 254×254, 동일 S=4.25) |
| 색공간 / 포맷 | sRGB, PNG-24 (무손실). 가정: 파일 상한 3MB, 초과 시 PNG-8 팔레트 폴백 |
| DPI 메타 | 72 (SNS 업로드 기준). 가정 |

**환산 규칙**: 미리보기 px × 4.25 = 렌더 px. 소수는 반올림하되 **서체 크기는 정수로 내림 후 −1px 하지 않는다**(Lexend 800의 힌팅 편차 방지). 아래 표의 렌더 값이 정본이고, 미리보기 값은 참고다.

### 3-4. 지표 줄 수에 따른 변형 (부분 완료)

완료 트랙 수가 줄면 **숫자를 키워 카드가 비어 보이지 않게** 한다. 빈 줄에 "–"나 회색 자리표시를 넣지 않는다(정본 §0-2.4 — 미실천을 세어 보여주지 않는다).

| 완료 트랙 | 지표 줄 | 9:16 숫자 / 단위 | 1:1 숫자 / 단위 | 줄 간격 | 환산 캡션 |
|---|---|---|---|---|---|
| 3개 | 3줄 | 247 / 77 | 128 / 46 | 42 / 28 | 없음 |
| 2개 | 2줄 | **289 / 89** | **160 / 55** | 55 / 38 | 없음 |
| 1개 | 1줄 | **391 / 119** | **220 / 72** | — | **1줄 허용** (§9-3) |
| 0개 | — | 카드 생성 안 함 | | | |

**걸음 미측정 시**: 활동 트랙을 완료했더라도 걸음 데이터가 없으면 T4-14를 **그리지 않고**, 대신 활동 분으로 대체한다. 둘 다 없으면 활동 줄 자체를 생략하고 줄 수를 재계산한다.

| 활동 데이터 상태 | 렌더 |
|---|---|
| 걸음 있음 | `6,400` `걸음` |
| 걸음 없음 + 활동 분 있음 | `22` `분 활동` |
| 둘 다 없음(체크인만) | **줄 생략** → 남은 줄 수로 §3-4 표 재적용 |

> 걸음 0은 "미측정"과 다르다. **0은 카드에 싣지 않는다**(0을 크게 박으면 무비난 원칙과 충돌). 값이 0이면 "둘 다 없음"과 동일 처리. 가정.

## 4. 금지 콘텐츠와 화이트리스트 렌더 파이프라인

### 4-1. 카드에 절대 싣지 않는 것

브리프 §4 말미 — "공유 카드에는 **건강 수치·밴드·구간을 어떤 경우에도 싣지 않는다**".

| # | 금지 대상 | 이유 (정본 근거) |
|---|---|---|
| 1 | 혈압·혈당·BMI·지질 등 **검진 수치** | §0-2.1 의료법 27조. 공유 이미지는 통제 불가한 채널로 퍼진다 |
| 2 | **밴드**(안정/주의/경고), **구간**(정상/주의/경고/미측정) | 동상. 밴드가 유출되면 질환 규정과 동치 |
| 3 | **연속 일수 끊김**·카운트다운 | §0-2.4 / §0-2.6 |
| 4 | **미완료 개수**·미실천 트랙 표시 | §0-2.4 무비난 |
| 5 | **순위·백분위·상위 n%**·리더보드 | §0-2.6 안티골 |
| 6 | 사용자 **이름·프로필 사진·아이디** | §12 개인정보 |
| 7 | 인과·효능 문구 ("물 마셔서 좋아졌어요") | §0-2.2 / §0-2.5 |

> "이번 달 이 캐릭터를 만난 사람은 12%"는 **분포 통계**이지 순위가 아니다(브리프 §4). 다만 카드 위에서 맥락 없이 `· 12%`만 보이면 순위로 오독될 수 있어 §11에서 카피를 조정한다.

### 4-2. 렌더 파이프라인 — fail-closed 화이트리스트

```
routine state  ─┐
daily metrics  ─┤→ build_card_payload()  ─→ CardPayload(dict)  ─→ render_card(payload) → PNG
archetype      ─┘   ① 밴드 게이트          ② 화이트리스트만    ③ 미지 키 → 렌더 거부
```

**① 밴드 게이트** — `band in {"경고", "응급"}` 이면 `build_card_payload()` 는 `None` 을 반환하고, 화면 진입점 자체가 사라진다. 카드 생성 API도 403.

**② 화이트리스트** — 페이로드는 아래 키만 **생성**한다. 상위 도메인 객체를 그대로 넘기지 않고, 필드를 하나씩 **복사해 새 dict를 만든다**(누락형이 아니라 열거형).

| 키 | 타입 | 출처 | 비고 |
|---|---|---|---|
| `date_label` | str | 카드 생성 시각 | `MM.DD DDD` 대문자 |
| `brand_label` | const | 고정 | `"TODAY'S ME"` |
| `metrics[]` | list ≤3 | 일일 집계 | `{kind, value:int, unit_label:str}` · `kind ∈ {water_cups, steps, mindful_min, active_min}` |
| `archetype_en` / `archetype_ko` / `archetype_lore` | str | 브리프 §4 표 (서버 상수) | 자유 입력 아님 |
| `rarity_pct` | int \| null | 월간 분포 집계 | 0~100. null이면 미표시 |
| `theme_id` | enum | 사용자 선택 | `coral / lavender / forest` |
| `stickers[]` | list ≤6 | 사용자 배치 | `{type, x:0~1, y:0~1, scale, rot}` |
| `comment` | str ≤20 \| null | 사용자 입력 | §10 필터 통과분만 |
| `hide_numbers` | bool | 토글 | true면 `metrics`·`rarity_pct` 를 **페이로드에서 제거** |

**③ 렌더러 방어** — `render_card()` 는 `CARD_ALLOWED_KEYS` 상수와 대조해 **미지 키가 하나라도 있으면 렌더를 거부**하고 에러를 올린다(무시하고 그리지 않는다 — 조용한 통과가 더 위험하다). 추가로 `CARD_FORBIDDEN_SUBSTRINGS = {"bp", "glucose", "band", "grade", "streak", "rank", "percentile", "missed", "name", "profile"}` 를 키 이름에 대해 검사한다.

**테스트 (필수)**

| 케이스 | 기대 |
|---|---|
| 금지 키(`systolic_bp`) 주입 | 렌더 예외, PNG 미생성 |
| `band="경고"` | `build_card_payload()` → None, 화면 진입점 미렌더 |
| `metrics` 4개 이상 | 스키마 검증 실패 |
| `comment` 21자 | 검증 실패 (클라이언트에서도 20자 하드 컷) |
| 스냅샷 테스트 | 7개 아키타입 × 3테마 × 2포맷 × {줄 1·2·3} PNG 골든 이미지 비교 |

**렌더 위치**: 서버 렌더 권장(폰트 임베드로 Lexend/Jua 미로드 리스크 제거, 골든 이미지 회귀 가능). 오프라인 대비 클라이언트 렌더 폴백을 둔다면 **동일 화이트리스트를 클라이언트에도 복제**한다. 가정.

## 6. 아키타입별 컬러 테마 3종

### 6-1. 테마 정의 (현재 → 제안)

목업의 `#FF7A59` + `#FFF3E0` 조합은 대비 **2.35:1** 로, 큰 텍스트 기준(3:1)에도 미달한다. 카드는 UI가 아니라 이미지라 WCAG 강제 대상은 아니지만, 저시력 사용자에게 그대로 공유되는 산출물이므로 **3:1 이상을 확보**하도록 배경을 한 단계 낮춘다.

| 테마 | ID | 배경 (현재 → 제안) | ink(본문·숫자) | accent-text(아키타입 EN) | 장식 | 대비 (ink / accent) |
|---|---|---|---|---|---|---|
| 선셋 코랄 | `coral` | `#FF7A59` → **`#E2593A`** | `#FFF3E0` | **`#FFF3E0`** (현재 `#FFD84D` → 제안) | `#FFD84D` | **3.36:1** / 3.36:1 |

| 딥 포레스트 | `forest` | (신설) **`#2F4A3A`** | `#EAF6EE` | `#A9B86B` | `#FFD84D` | **8.60:1** / **4.50:1** |

사용자가 바꾸기 전 초기값. 트랙 원소색(브리프 §3)과 어긋나지 않게 잡는다.

### 8-3. 캐릭터 도감 자동 저장

- 화면 4 **진입 시점에 1차 저장**(아키타입·날짜·지표 스냅샷·기본 테마). 이후 테마·스티커·코멘트 편집은 **디바운스 800ms 후 자동 갱신**. 저장 버튼 없음.
- **재편집 창 = 기록일 당일 00:10까지**(정본 25 E01 유예, C5 확정). 창이 닫히면 레코드는 불변이 되고 화면은 읽기 전용(§5)으로만 열린다. **카드 재생성(다시 만들기)은 어떤 경로로도 제공하지 않는다** — 이미 공유된 이미지와 도감이 어긋나는 것을 막는다.
- 도감 레코드: `card_id, date, archetype_id, theme_id, stickers[], comment, hide_numbers, metrics_snapshot`. `metrics_snapshot` 은 **도감 내부 표시용**이며 §4-2 화이트리스트를 그대로 통과한 값만 담는다.
- 공유 실패·미공유도 도감에는 남는다. "공유해야 저장된다"는 압박을 만들지 않는다.

## 14. 엣지 케이스

| 케이스 | 처리 |
|---|---|
| **자정 넘김** | 카드는 **귀속된 기록일**을 고정한다(정본 25 E01 유예, C1). 23:58 생성 → 00:05 공유해도 `09.02 TUE`. **00:10까지는 재편집이 열려 있고, 00:10을 넘기면 읽기 전용**(§5)으로 잠긴다 |
| **걸음 연동 지연** | **카드 재생성은 불허**(C5). 화면 진입 시 1회 강제 동기화로 선제 반영하고, 그래도 늦게 올라오면 **이미 생성된 카드는 그대로 둔다**(재생성·덮어쓰기 모두 없음). 홈 배너 `걸음이 늦게 들어왔어요` (11자)로 사실만 알리고 `카드 새로 만들기` 버튼은 **제공하지 않는다** — 공유된 이미지와 도감의 불일치를 만들지 않기 위함 |
| **되돌리기 만료** | 화면 1의 5분 되돌리기가 만료된 뒤 완료 취소는 불가. 이미 생성된 카드도 유지 |
| **되돌리기 유효 중 완료 취소** | 완료 트랙이 줄면 아키타입이 바뀔 수 있다. 그래도 **카드를 재생성하지 않는다**(C5). 이미 만들어진 카드와 도감 레코드는 **생성 시점의 아키타입으로 고정**된다. 이미 외부로 공유된 이미지도 회수 불가하므로, 취소 확인 다이얼로그에 `공유한 카드는 바뀌지 않아요` (14자)를 1줄 넣는다 |
| **"해당없음"** | 해당 트랙을 아키타입 계산에서 제외한다(브리프 §4). 지표 줄도 생성하지 않는다. "해당없음" 자체를 카드에 적지 않는다 |
| **첫날 D1** | 특별 처리 없음. 카드도 동일. D1 첫 성공 전면 모달은 화면 1의 예외이며 이 화면과 무관 |
| **오프라인** | 로컬 렌더 카드로 T4-42만 활성. 도감 저장은 큐에 넣었다가 온라인 시 동기화 |
