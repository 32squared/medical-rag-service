## 2. 적용 범위 가정

마이헬스케어 루틴 제품(레포 `docs/plan/27-routine-content.md` 정본) 위에 얹는 **재미 레이어**로 가정한다. 따라서 정본의 어휘 표준·금칙·글자수 예산을 그대로 따른다. 핵심만 요약:

- 어휘: 트랙 이름은 **식이 기록 / 활동 기록 / 생활 리듬**. 미실천은 "쉬어간 날"(회색 '–'). "실패·결석·미달·놓친 날" 금지.
- 금칙: 질환명으로 사람 규정 금지, 건강 결과 약속 금지(행동만 말한다), 용량·처방 표현 금지, **미완료 개수·연속 끊김 카운트다운·붉은색 죄책감 표현 금지**, 인과 주장 금지, **랭킹·리더보드·전면 축하 모달(자동 팝업)·밴드 개선 연동 보상 금지**.
- 밴드 캡: 안정·주의 밴드는 게임 요소 전부 노출. **경고 밴드는 캐릭터·카드·연속 일수 전부 숨김**(측정·기록형 문구로 치환).
- 글자수: 오늘의 행동 문구 30자 이내, 메타 캡션 20자, 코치 한 줄 30자, 버튼 라벨 12자, 질문칩 24자.
- 체크인 3버튼: **오늘 완료하기 / 못했어요 / 해당없음**. 피드백 문구는 정본 §3-1 그대로. 못했어요 직후 사유 태그 4개(§3-2). 5분 내 되돌리기.

## 3. 3트랙 ↔ 원소 ↔ 대표 지표

| 트랙 | 대표 지표 | 캐릭터 원소 | 색 |
|---|---|---|---|
| 식이 기록 | 물 컵 수 (1컵 = 200mL) | 물방울 | #4C86F0 (타일 #AFC9F5) |
| 활동 기록 | 걸음 · 활동 분 | 번개 | 면 #FFB800 / 점·강조 #FF8A5B |
| 생활 리듬 | 마음챙김 분 · 취침 시각 | 달 | #8E7BEF (타일 #CDBFF7) |

- 완료 판정(잠정, E1 에스컬레이션): 물 6컵 / 걸음 6,000 / 마음챙김 1분 타이머 1회. "깨어남"(부분 입력에 캐릭터가 반응)과 "완료"는 별개다.
- 환산 계수: 화분 1개 = 2컵, 한강 다리 1개 = 3,000걸음, 노래 1곡 = 3.5분(상한 8곡). 환산 수량이 0이면 문구를 렌더하지 않는다.
- 기록일 경계는 로컬 00:00, 자정 유예는 정본 25 E01(23:50~00:10 탭은 전날 귀속). 취침 시각만 05:00 이전은 전날 밤으로 귀속.
- 걸음 연동 지연 임계 30분. 화면 진입 시 1회 강제 동기화.

## 4. 아키타입 결정 규칙

완료한 트랙의 **조합**으로만 결정한다. 안 한 트랙은 계산에 들어가지 않는다.

| 완료 조합 | 아키타입 (EN / KO) | 한 줄 로어 |
|---|---|---|
| 식이만 | Hydration King 수분왕 | 오늘 몸의 70%를 책임진 사람 |
| 활동만 | Step Wizard 걸음술사 | 지도 위에 오늘 하루를 그렸어요 |
| 생활 리듬만 | Mindful Warrior 마음의 전사 | 폰보다 먼저 눈을 감은 자 |
| 식이+활동 | Sunny Runner 햇살 러너 | 마시고 달리는 낮의 사람 |
| 활동+리듬 | Night Owl, Reformed 개과천선 올빼미 | 움직이고 일찍 잔 기적 |
| 식이+리듬 | Zen Barista 젠 바리스타 | 물 한 잔, 숨 한 번 |
| 셋 다 | Balance Monk 밸런스 수도승 | 오늘 세 가지 모두 완료 |
| 0개 | **리빌 없음** | "쉬어간 날"로만 기록. 캐릭터·카드 생성 안 함 |

- 희귀도: "이번 달 이 캐릭터 만난 사람 12%"(20자)처럼 **남과 비교하지 않는 분포 통계**만. 순위 없음. 표본 하한 100명, 미달 시 희귀도 줄을 숨기고 로어를 노출. 카드에는 "이달 12%"로 병기.
- 리빌 화면은 **사용자가 버튼을 눌러 여는 화면**이다. 자동 팝업·전면 모달 아님. 푸시·딥링크로 직행하지 않는다.
- 주간 스트립 점·"N일째 이어졌어요"는 **행동 카드 체크인** 기준(정본). 아키타입·링·화면 2 진입 조건(≥1)은 **3트랙 완료** 기준. 두 개념을 섞지 않는다.
- 과거 날짜의 리빌은 연출 없이 결과만 재열람 가능. 카드 재생성은 불허, 카드 재편집은 당일 00:10까지.
- 경고 밴드: 캐릭터·카드·도감 진입점 자체를 노출하지 않는다. 화면 2 CTA는 "이번 주 기록 보기"로 치환.
- 공유 카드에는 **건강 수치·밴드·구간을 어떤 경우에도 싣지 않는다.** 행동 지표(컵·걸음·분)와 캐릭터만.

### 4-2. 웰니스 타입 5종 (성향 아키타입 · 2026-09-03 채택안 B)

하루 캐릭터 7종과 **별개의 층**이다. 7종은 "오늘 무엇을 했나"의 결과이고, 5종은 "나는 어떤 웰니스 사람인가"의 자기 정의다. 두 층은 서로의 결정에 관여하지 않는다.

| type_id | 이름 (KO / EN) | 한 줄 정의 | 기본 카드 테마 |
|---|---|---|---|
| `miracle_morning_dreamer` | 새벽 감성 야망가 / Miracle Morning Dreamer | 새벽 5시에 물 마시고 명상하지만 저녁 8시면 방전 | lavender |
| `micro_wellness_sloth` | 마이크로 웰니스 나무늘보 / Micro-Wellness Sloth | 헬스장 대신 이불 정리·3분 호흡으로 마음의 평화를 지킴 | forest |
| `healthy_pleasure_foodie` | 헬시 플레저 미식가 / Healthy Pleasure Foodie | 운동 뒤 고단백 간식과 제로 디저트로 스스로 보상 | coral |
| `ritual_fairy` | 유리멘탈 리추얼 요정 / Ritual Fairy | 향·일기·호흡으로 무너진 마음을 정성껏 복구 | lavender |
| `baby_godsaeng` | 갓생 신생아 / Baby God-Saeng | 물 한 잔·비타민 하나에도 뿌듯한 시작 단계 | coral |

- **배정**: 온보딩 문진 4문항(§4-3)으로 1회 배정. 설정에서 언제든 직접 변경 가능. 행동 패턴 기반 재배정 제안은 v2(P2).
- **반영 위치**: ① 설정·프로필의 "내 웰니스 타입" 카드 ② 공유 카드 하단 라벨 "○○ 타입"과 기본 테마 ③ 온보딩 직후 공유 가능한 "타입 카드"(P1) ④ 코치 한 줄 말투 변형(P2).
- **금칙**: 타입 간 우열·등급 없음. 밴드·건강 판단과 무관하며 어떤 타입도 질환·위험을 암시하지 않는다. 경고 밴드에서도 타입 자체는 유지하되 **카드·타입 카드는 숨긴다**(카드 금칙과 동일). 타입을 근거로 행동을 강제하거나 "타입에 안 맞아요"류 문구를 쓰지 않는다.
- 일러스트 5종 프롬프트는 `03-archetype-image-prompts.md`.

### 4-3. 온보딩 문진 4문항 (타입 배정)

각 문항은 5지선다, 선택지마다 타입 1개가 대응한다. 최다 득표 타입으로 배정하고, 동점이면 **Q4 답**이 우선한다(자기 정의를 존중).

| # | 질문 | 야망가 | 나무늘보 | 미식가 | 요정 | 신생아 |
|---|---|---|---|---|---|---|
| Q1 | 하루 중 가장 나다운 시간은? | 해 뜨기 전 새벽 | 침대 위 아무 때나 | 운동 끝난 직후 | 밤, 혼자만의 시간 | 아직 찾는 중 |
| Q2 | 오늘 딱 하나만 한다면? | 물 한 잔과 명상 | 이불 정리와 3분 호흡 | 운동하고 맛있는 것 | 향 피우고 일기 쓰기 | 비타민 하나 챙기기 |
| Q3 | 힘든 날의 나는? | 일찍 자고 새벽에 다시 | 아무것도 안 하고 쉼 | 땀 빼고 맛있게 먹기 | 글로 마음 풀기 | 하나만 하고 나를 칭찬 |
| Q4 | 나에게 웰니스란? | 목표 | 평화 | 즐거움 | 회복 | 시작 |

- 문항·선택지는 질환·수치·의료 어휘를 쓰지 않는다(정본 §0-2). 선택지 라벨 12자 이내.
- 결과 화면 카피: "당신은 **{타입명}** 타입이에요" + 한 줄 정의. "정확도"·"분석 결과"류 과학적 단정 표현은 쓰지 않는다.

## 5. 4화면 흐름과 목업 파일

```
Main.dc.html   1 · Daily Tracker  (오늘의 체크인)      배경 #FFD84D
Stats.dc.html  2 · Daily Stats    (오늘의 기록)        배경 #CDBFF7
Reveal.dc.html 3 · Archetype Reveal (오늘의 캐릭터)    배경 #F5A8D8
Card.dc.html   4 · Share Card     (공유 카드)          배경 #BFE8CF
```

- 흐름: 1 → (트랙 1개 이상 완료 시 "오늘의 기록 보기" 활성) → 2 → (하단 CTA "오늘의 캐릭터 만나기") → 3 → ("카드 만들기") → 4. 0트랙 상태의 화면 2는 캘린더 경로로만 진입.
- 화면 1은 **하루 중** 상태(물방울만 깨어남), 화면 2~4는 **하루 끝** 상태(3트랙 모두 완료 → Balance Monk)를 그린 샘플이다.
- 샘플 값: 물 6컵(= 작은 화분 3개), 6,400걸음(= 한강 다리 2개), 마음챙김 7분(= 노래 2곡), 5일째 이어짐, 희귀도 12%, 날짜 9월 2일 화요일.

## 6. 비주얼 시스템 (목업 기준)

- 서체: Lexend(숫자·영문 디스플레이) + Jua(한글 헤드라인) + Gowun Dodum(한글 본문). 폴백 Malgun Gothic.
- 톤: 캔디 파스텔 풀컬러 배경, 청키 플랫 벡터 캐릭터, 큰 라운드(24~32px) 카드, 기울어진 카드 스택, 화면 가장자리로 삐져나오는 장식(4각 별, 꽃 모양, 색점).
- 검정 알약 CTA(#141414), 흰 알약 보조 버튼. 최소 탭 영역 44px.
- 앱 밖으로 나가는 산출물(공유 카드)은 잉크 대비 3:1 이상. 카드 코랄 기준색 #E2593A(목업 #FF7A59는 2.35:1로 교체).
- 0·미측정 공통 스타일: 회색 #7A7A7A "–" + 캡션. 아키타입 배경 신규 토큰 #FFC98F(햇살 러너), #E4EBC7(젠 바리스타)은 대비 실측 후 확정.
- 화면 1은 트랙 타일까지 above the fold, 이후 스크롤, 하단 내비 고정. 토스트 글자수 예산 30자.
- 카드 목업 실측 254×452, 스케일 4.25 → 1080×1920.
- 아이콘은 인라인 SVG 스트로크. 이모지 사용 안 함. 가짜 iOS 상태바 그리지 않음(상단 56px 비움).

## 7. 세부기획서 공통 목차 (화면별 기획서는 이 순서를 따른다)

10. 열린 질문 · 브리프 변경 제안
