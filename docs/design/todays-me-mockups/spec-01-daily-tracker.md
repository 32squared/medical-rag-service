### 3-2. 트랙 타일 상태 — 캐릭터 잠듦 ↔ 깨어남

이 화면의 고유 규칙. **한 트랙에 상태 2개(잠듦/깨어남) + 완료 뱃지 1개**를 분리해서 쓴다.

| 트랙 | 잠듦(z 표시, 눈 감음) | **깨어나는 트리거** | 깨어남 유지 | 다시 잠듦 |
|---|---|---|---|---|
| 물 | 오늘 0컵 | **첫 1컵 입력 순간** | 1컵 이상 | 되돌려 0컵이 되면 |
| 걸음 | 연동값 < 임계 & 수동 입력 없음 | **연동값이 임계 도달**(가정: 1,000걸음) 또는 수동 보정 저장 | 임계 이상 | 되돌리기로 0 |
| 마음 | 타이머 미실행 | **타이머 시작 시점**(0초) — 완주 전이라도 깨어남 | 세션 종료까지 | 중단 후 진행분 0이면 |

- 깨어남 ≠ 완료(교차 검수 A2). **완료 뱃지**(T1-21b~23b)는 §2-3의 목표 도달에서만 채워지고, 아키타입 계산에는 **완료 뱃지만** 들어간다.
- **두 기준선을 섞지 않는다**(교차 검수 C6): 주간 스트립 점·`N일째` = 행동 카드 체크인 / 아키타입·링·화면 2 진입(≥1) = 3트랙 완료.
- 자정 롤오버 시 세 트랙 전부 잠듦으로 초기화한다.
- 애니메이션: 눈 뜨기 260ms + 미세 바운스 140ms, 합 ≤ 400ms. `prefers-reduced-motion`이면 크로스페이드 120ms.

**현재 → 제안**: 목업의 물 타일은 `4컵째`인데 완료 뱃지가 채워져 있다. 목표 6컵과 어긋난다 → **목표 미도달이면 뱃지는 테두리만**, 도달 시 채움. 캡션도 `4컵째 · 깨어 있음` → 도달 시 `6컵 · 완료`(6자).

### 3-3. 첫날 D1 특례

교차 검수 **C8 판정**: 정본 H2의 전면 축하 1회는 **행동 카드 첫 체크인(T1-13)의 것**이다. 아키타입 리빌(화면 3)은 사용자가 버튼을 눌러 여는 **별개 화면**이며 축하 예외와 무관하다.

| 요소 | 규칙 |
|---|---|
| 숨김 | Z7 주간 스트립, T1-20 보조 카드, 아키타입 희귀도 문구 |
| Day3Stepper | `●○○` + `작심삼일, 오늘 하나만 하면 시작이에요` |
| **전면 축하** | **T1-13 첫 체크인 완료 시 1회만** 전면 시트(정본 H2 §1-7). 헤드라인 `첫 기록이 남았어요` / 본문 `내일 같은 시각에 하나만 더. 3일을 넘기면 자리가 잡혀요.` / CTA `홈으로 돌아가기` |
| 트랙 완료·리빌 | 전면 축하를 **띄우지 않는다**. T1-24 티저 문구만 갱신 |
| **같은 날 겹칠 때 순서** | ① T1-13 체크인 완료 → ② H2 전면 축하 1회 → ③ **홈(화면 1) 복귀** → ④ 사용자가 T1-24 티저 또는 T1-29를 눌러야 리빌 진입. 축하 시트에서 리빌로 직행시키지 않는다 |
| 이후 | D2부터는 전면 금지. 인라인 tint + 코치 한 줄만 |

### 5-2. 환산 문구 규칙

| 지표 | 환산 | 예 |

### 5-3. 아키타입 프리뷰 계산

```
complete = [t for t in (water, steps, mind) if tracks[t].complete]
preview  = ARCHETYPE[frozenset(complete)]   # 브리프 §4 표
if len(complete) == 0: preview = None       # 리빌 없음
if safety.band == '경고': preview = HIDDEN  # 티저 행 미렌더
```

**미완료 트랙은 어떤 계산·문구에도 등장하지 않는다.**

**기준선 분리 (교차 검수 C6)** — 두 계산을 같은 입력으로 묶지 않는다.

| 산출물 | 입력 | 필드 |
|---|---|---|
| 아키타입 프리뷰(T1-24·26) · 캐릭터 링 · T1-29 활성(≥1) | **3트랙 완료 뱃지** | `tracks.*.complete` |
| 주간 7점 스트립(T1-28) · `N일째 이어졌어요` · 연속·주간 미션 | **행동 카드 체크인** | `today.status` · `week_days[7]` |

- `today.status == 'done'`이어도 완료 트랙이 0이면 아키타입은 `None`이고 T1-29는 비활성이다.
- 반대로 3트랙을 다 완료해도 행동 카드 체크인이 없으면 스트립 점은 채워지지 않는다.
- 완료 판정 임계값은 브리프 §3 잠정값(A2)이며 **E1 결정 대기**다.
