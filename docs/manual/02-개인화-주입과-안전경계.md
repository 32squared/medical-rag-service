# 02. 개인화 주입과 안전 경계

해석 엔진이 만든 findings를 **답변에 결합하는 계층**(경계선 ③). 관련성 게이트로 상황에 맞는
신호만 골라 중립 블록으로 렌더하고, 안전 백스톱을 통과한 것만 주입한다.

- 코드: [`personal_context.py`](../../personal_context.py), [`personalization_safety.py`](../../personalization_safety.py)
- 주입 지점: [`rag_engine.py`](../../rag_engine.py) `generate_response`
- 테스트: `tests/test_personal_context*.py`, `tests/test_persona_e2e.py`

## 핵심 API — `safe_block`

```python
from personal_context import safe_block

findings = ...  # vital_rules.run + run_trends + env_rules ...
block = safe_block(findings, query="혈압이 높게 나왔는데 괜찮을까요?")
# → "## 📋 내 기록 참고\n- 최근 측정된 혈압은(는) 기준을 벗어난 구간으로, 의료진 확인이 권장됩니다.\n\n측정값의 해석과 진단은 의료진과 상담하세요."
```

- 반환은 **그대로 답변에 후append 가능한 문자열**.
- 관련성 게이트 통과 0 또는 안전 위반 → `""`(주입 안 함, fail-closed).

## 관련성 게이트 (과노출 차단)

질의에 해당 신호의 **scope 키워드**가 있어야 그 finding이 표면화된다.

| signal | scope 키워드(일부) |
|---|---|
| blood_pressure | 혈압, 고혈압, 어지럼, 두통 |
| spo2 | 산소, 호흡, 숨, 기침, 가래 |
| body_temperature | 열, 발열, 체온, 미열, 오한 |
| bmi | 체중, 비만, 체질량 |
| air_quality | 기침, 가래, 숨, 공기, 환기, 알레르기 |

- 예: 고혈압 findings가 있어도 질의가 "감기약 먹어도 되나요?"면 → **블록 없음**(무관 → 미표면화).
- 밴드 라벨(안정/주의/경고) 보유 finding **또는** 자체 `sentence`(추세·환경) 보유 finding만 통과.
- 교차신호 조합은 조합 신호 중 하나라도 scope에 걸리면 표면화.

## 블록 형태

```
## 📋 내 기록 참고
- 최근 측정된 혈압은(는) 기준을 벗어난 구간으로, 의료진 확인이 권장됩니다.
  안정을 취한 뒤 다시 측정하고, 높은 상태가 반복되면 의료진 진료를 권해드려요. 심한 두통·가슴 통증·한쪽 팔다리 마비·말 어눌함·갑작스런 시야 이상이 있으면 지체 말고 응급실을 이용하세요.
- 최근 여러 차례 측정에서 혈압이(가) 점차 높아지는 흐름입니다.
- 혈압과 체질량지수를 함께 살펴보면 좋은 시점입니다.

측정값의 해석과 진단은 의료진과 상담하세요.
```

### 밴드별 행동 안내(`_GUIDANCE`)

각 밴드 finding 아래에 **다음-행동 한 줄**을 붙인다(navigation·안전, 비진단).
- **경고** → 재측정 + 진료 권유 + **적신호 시 응급실**(혈압·체온·산소별 적신호 다름).
- **주의** → 재측정/추이 + 가벼운 관리 안내(예: 혈압은 싱겁게·걷기·체중·절주).
- **안정** → 안내 없음(과의료화 방지).
- 제약: **2자리+ 숫자 금지**(119·수치 미사용 → "응급실" 표현)·질환명 0 — C20/C21 통과 보장.

중립 라벨 → 사용자 문구 매핑:

| label_user | 문구 |
|---|---|
| 안정 | 현재 측정 기준으로는 특이소견이 보이지 않습니다 |
| 주의 | 관리가 권장되는 구간으로 확인됩니다 |
| 경고 | 기준을 벗어난 구간으로, 의료진 확인이 권장됩니다 |

## 안전 백스톱 — `personalization_safety` (C20/C21)

`safe_block`이 내부에서 `assert_personal_block_safe(block)`를 호출한다. 위반 시 `""` 반환.

- **C20** `scan_personal_block`: 블록에 원시 측정값/질환 명사가 섞이면 차단(주입 안 함).
- **C21** `find_clinical_labels`: 종결어미 정규식이 놓치는 **명사형 진단**("고혈압", "당뇨병")을 잡는다.

## 생성 파이프라인 주입 (rag_engine)

`generate_response(query, conversation_id, ..., personal_findings=None)`:

1. 개인 데이터는 **LLM 프롬프트에 미투입**.
2. LLM이 답변 생성 후, `not emergency_detected`일 때만:
   ```python
   _pblock = personal_context.safe_block(personal_findings, query)
   if _pblock:
       full_text = full_text.rstrip() + "\n\n" + _pblock
   ```
3. **I7**: 응급 감지(`intent=='emergency'`) 시 개인화 결합 억제 — 응급 안내가 우선.
