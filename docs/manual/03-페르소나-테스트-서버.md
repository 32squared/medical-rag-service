# 03. 페르소나 테스트 서버

페르소나를 골라 **개인화 대화를 로컬에서 시험**하는 도구. 백엔드 없이도 개인화 블록을
결정적으로 미리보고, RAG 서버를 연결하면 라이브 대화까지 한다.

- 코드: [`persona_test_server.py`](../../persona_test_server.py)
- 데이터: [`test_personas/personas.json`](../../test_personas/personas.json) (24종)
- 테스트: `tests/test_personas_dataset.py`

## 실행

```bash
# 1) 미리보기 전용 — 백엔드/DB/LLM 불필요
python persona_test_server.py
# → http://localhost:8770

# 2) 라이브 대화 — 로컬 rag_server 또는 클라우드 연결
python persona_test_server.py --rag-url http://127.0.0.1:8080
python persona_test_server.py --rag-url https://...run.app   # gcloud 토큰 자동
```

- 로컬 대상은 `RAG_TRUST_SECRET` 미설정 시 트러스트 통과.
- 클라우드(`.run.app`) 대상은 `gcloud auth print-identity-token`을 자동 부착.

## 화면

- **좌측**: 페르소나 드롭다운 + 프로필/태그 + **📋 개인화 미리보기**(밴드 findings + 결합될 블록).
  - 항상 동작(결정적·로컬). **원시값 미노출**, 사용자 라벨만.
- **우측**: 대화 로그 + 샘플질의 칩. 질문을 보내면 결합될 '내 기록' 블록을 함께 표시.
  - `--rag-url`가 있으면 같은 페르소나의 `agent_input_field_to_value`를 실어 라이브 SSE.

## 엔드포인트

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/` | 테스트 UI |
| GET | `/personas` | personas.json |
| POST | `/preview` | `{persona_id, query}` → `{findings, safe_block, summary, agent_input}` (로컬·결정적) |
| POST | `/chat` | 페르소나 개인화를 실어 `/api/service/conversations/{graph}`로 SSE 프록시 |

## 페르소나 데이터셋 스키마

```json
{
  "id": "hypertension_senior",
  "name": "고혈압 관리 어르신", "emoji": "👴",
  "profile": "67세. 가정혈압 측정 습관 ...",
  "tags": ["고혈압", "시니어", "복약"],
  "locale": "KR", "population": "adult", "context": "clinic",
  "vitals": [{"bps":152,"bpd":96,"bpm":78,"spo2":97,"create_date":"..."}],
  "air_quality": "보통",
  "phr": "{\"meds\":[\"antihypertensive\"]}",
  "expected_label": "혈압 경고(고혈압 1기)",
  "sample_queries": ["혈압이 높게 나왔는데 괜찮을까요?", "뒷목이 뻐근해요"]
}
```

- `vitals`는 `agent_input_field_to_value`의 `"Vital Signs"`(JSON 배열 문자열)로 직렬화된다
  (계약: [`vital_input.parse_agent_inputs`](../../vital_input.py)).
- `vitals`가 3회+면 추세 노트가, `air_quality`가 나쁨/매우나쁨이면 환경 노트가 함께 결합된다.

## 24 페르소나 커버리지

밴드 분포(안정/주의/경고)와 시나리오를 고루 포함:

- 혈압: 안정·주의·경고(1기/2기)·저혈압·상승추세(다회측정)
- 호흡기/산소: 저SpO2·COPD 이력·흡연자·감염 의심
- 발열: 고열·미열·청소년 고열·소아 보호자(성인 밴드 미적용)
- 대사/결합: 혈압+BMI 교차신호·당뇨 추적
- 기타: 운동선수 서맥·불안 두근거림·임신 복약·산후·고령 쇠약·편두통·검진 풀이·흉통 응급

각 페르소나는 vitals + PHR + 환경(공기질)을 상황에 맞게 채운다(`tests/test_personas_dataset.py`가 완비 검증).

## 라이브 백엔드(선택) 준비

라이브 대화를 쓰려면 RAG 서버가 떠 있어야 한다(PostgreSQL + `OPENAI_API_KEY`).
로컬 PG end-to-end는 [`SETUP-PG.md`](../SETUP-PG.md) / `setup_local_pg.py` 참고.
미리보기만 쓸 거면 백엔드 없이 그대로 사용한다.
