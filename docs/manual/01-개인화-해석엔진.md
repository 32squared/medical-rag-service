# 01. 개인화 해석 엔진

개인 측정값을 **결정적으로(LLM 비의존)** 해석해 중립 라벨/노트(findings)로 변환하는 계층.
원시값은 여기서 끝나고, 밖으로는 라벨만 나간다(경계선 ②).

- 코드: [`vital_rules.py`](../../vital_rules.py), [`env_rules.py`](../../env_rules.py)
- 참조범위 시드: [`seed_reference_ranges.py`](../../seed_reference_ranges.py)
- 테스트: `tests/test_vital_rules*.py`, `tests/test_trends.py`, `tests/test_cross_signal.py`, `tests/test_env_rules.py`

## 해석 4축

| 축 | 함수 | 입력 | 출력 finding |
|---|---|---|---|
| 밴드 | `lookup_band` / `run` | 단일 측정 | `label_user`(안정/주의/경고) |
| 추세 | `run_trends` / `label_trend` | 시계열(3회+) | 중립 흐름 노트(지속상승/저하/불안정) |
| 환경 | `air_quality_finding` | 공기질 | 환기 권유 노트(비인과) |
| 교차신호 | `match_cross_signals` | findings 묶음 | 화이트리스트 조합 노트 |

## 1) 밴드 해석 — `lookup_band` / `run`

```python
from vital_rules import lookup_band, run

# 다축(혈압): dict, 단축: 스칼라
lookup_band("blood_pressure", {"systolic": 152, "diastolic": 96})
# → {'signal_key':'blood_pressure','label_user':'경고','clinical_label':'고혈압 1기',
#    'match':'ok','context':'clinic','locale':'KR','cite_doc_id':...}

# vital_input 레코드 → findings (match=='ok'만)
run({"bps": 152, "bpd": 96, "bpm": 78, "spo2": 97})
# → [{blood_pressure 경고}, {heart_rate 안정}, {spo2 안정}]
```

**인자**: `context`(clinic/home), `locale`(KR/GLOBAL 폴백), `population`(adult/all 폴백), `device_grade`.

**지원 신호**(vital_input 필드 → signal): `bps`+`bpd`→`blood_pressure`, `bpm`→`heart_rate`,
`spo2`→`spo2`, `fever`→`body_temperature`, `bmi`→`bmi`. (`stress`는 공인 밴드 없어 스킵.)

**불변식**:
- **I1**: 반환 dict에 원시값(120 등)·min·max 없음. 라벨만.
- **fail-closed**: 매칭 0/축 결손/미지원 로케일·context → `match!='ok'` → 표면화 안 함.
- **보수성**: 여러 카테고리에 걸치면 가장 보수적(경고>주의>안정) 라벨 채택.
- **I12**: `label_user`(중립 3단)는 사용자용, `clinical_label`("고혈압 1기")은 내부 감사용.
- **I8 deny**: `device_grade='wellness'` 또는 `DENY_SIGNALS`(ecg·afib_alert 등) → `match='denied'`.

## 2) 추세 — `run_trends` (정본 14 §6.2)

```python
from vital_rules import run_trends
run_trends([{"bps":138},{"bps":144},{"bps":150},{"bps":156}])
# → [{'signal_key':'blood_pressure','kind':'trend','trend':'지속상승',
#     'sentence':'최근 여러 차례 측정에서 혈압이(가) 점차 높아지는 흐름입니다', ...}]
```

- 신호별 시계열에 `label_trend` 적용. **지속상승/지속저하/불안정반복만** finding으로 발화.
- **안정유지·표본부족(3회 미만)은 미발화**(노이즈 억제).
- 데이터 패턴만 기술 — '악화/호전' 같은 건강 판단은 하지 않는다(중립).

## 3) 환경 — `air_quality_finding` (5층 환경×건강)

```python
from env_rules import air_quality_finding
air_quality_finding("나쁨")   # → 주의 + '환기를 권장합니다' 노트
air_quality_finding("매우나쁨") # → 경고
air_quality_finding("보통")    # → None (fail-closed)
air_quality_finding(300)       # → 경고 (CAI 수치도 매핑)
```

- **비인과(B5)**: 공기질을 증상의 확정 원인으로 단정하지 않음. '좋지 않은 수준 + 환기 권유'가 천장.
- 보통/좋음/미상 → None(미발화). 실내 한정.

## 4) 교차신호 — `match_cross_signals` (I9 화이트리스트)

```python
from vital_rules import run, match_cross_signals
findings = run({"bps":150,"bpd":95,"bmi":27.4})   # 혈압 경고 + BMI 주의
match_cross_signals(findings)
# → [{'combo_id':'metabolic.bp_bmi','text':'혈압과 체질량지수를 함께 살펴보면 좋은 시점입니다', ...}]
```

- **화이트리스트(`_CROSS_WHITELIST`)에 등재된 조합만** 발화. 구성 신호가 모두 존재하고 모두
  `min_label`(주의) 이상일 때만.
- **유사과학 조합 차단**: `wellness_only` 조합(HRV+수면="번아웃" 등)은 영구 미발화.
- 단일 신호만 있으면 미발화(fail-closed).

## findings 스키마(공통)

```python
{
  "signal_key": "blood_pressure",       # 또는 air_quality / bmi ...
  "label_user": "경고",                 # 밴드: 안정/주의/경고 · 추세/환경: None 가능
  "clinical_label": "고혈압 1기",        # 내부 감사용(I12) — 표면화 금지
  "match": "ok",                        # ok / no_match / denied
  "cite_doc_id": "...",                 # 동반적재용 인용 forward-ref
  "kind": "trend" | "environment",      # (선택) 자체 sentence 보유 finding
  "sentence": "...",                    # (선택) 렌더 문장 오버라이드
}
```

→ 이 findings를 답변에 결합하는 방법은 [02. 개인화 주입과 안전 경계](02-개인화-주입과-안전경계.md).
